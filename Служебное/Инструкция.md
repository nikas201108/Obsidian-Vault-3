## Иконки (плагин «Iconize»)
Отвечает за иконки в заметках, в табе
- Иконки для вкладок или заметок назначаются в редакторе
- Иконки в заметках назначаются командой `:<имя>`
- Для добавления собственных иконок достаточно в настройках плагина добавить библиотеку `.svg` иконок
- У иконок может быть изменен цвет

## Вложенные списки (плагин «Lawlist»)
Отвечает за значки во вложенных списках и табуляцию
- Значки во вложенных списках могут быть изменены в настройках

## Эффективный проводник (плагин «File-Explorer-Plus»)
Позволяет закреплять папки и заметки, скрывать их
- В настройках есть пункт, который отвечает за видимость файлов. Можно включить или выключить отображение скрытых файлов

## Focus Mode

## Умная сортировка (плагин «Custom file explorer sorting»)
- С помощью панели закладок можно явно задавать положение файла в иерархии
- С помощью создания файла sortspec в папке можно задать тип сортировки внутри её (важны пробелы, а сам текст вставляется как свойство)
- Параметры для файлов содержатся в документации

## Плагин «Tracker»
Позволяет отображать статистику и динамику тех или иных величин 

Краткое руководство:
- Работа с данными: 
	- Общие аргументы:
		-  Названия данных задаются через параметр `datasetName`
		- Деление поля на значений происходит с помощью индексов; поля делятся с помощью слеша, запятой, но можно указать собственный разделитель через `separator`
		- 		 Папка поиска указывает через `folder`
		- 		 `startDate` и `endDate` задают начало и конец промежутка заметок, с которых берётся информация (указывается либо явно, либо относительно)
	- `searchType: frontmatter`
		-   `searchTarget:` поле
		- `searchTarget: deepValue.very` — ({"very":1})
	- `searchType: tag` 
		- `searchTarget:` тег
	- `searchType: text`
		- `searchTarget:` текст
	- `searchType: dvField` — поиск среди конструкций `dataTarget::` 
		- `searchTarget:` имя 
	- `searchType: fileMeta`
		- `searchTarget: size`
		- `searchTarget: cDate`
		- `searchTarget: mDate`
		- `searchTarget: numWords`
		- `searchTarget: numChars`
	- `searchType: table`
		- `searchTarget`: ссылка на X (`data/Tables[1][0]` — вторая таблица, столбец 1), ссылки на Y
	- `searchType: task/task.done/task.notdone`
		- `searchTarget:` задача
	- `searchType:`
		- `searchTarget: wiki.display` — текст самой ссылки
		- `searchTarget: wiki.link` — заголовок страницы
	- `file`: data/data1, data/data2, data/data3 — поиск по определнным файлам
	- `accum:` false/true — работа с данными в режиме накопления (line)
	- `penalty:` значение — штраф за отсутствие значения (line)
	- 	`stack`: true (bar)
	- Плагин поддерживает работу со временем (например, на осях)
	- `dateFormat`: сочетание Y-M-D
	- `dateFormatPrefix:`/`dateFormatSuffix`: значение
	- `textValueMap`: 
		- `ключ1`: `значение1`
		- `ключ2`: `значение2`
	- `xDataset:` явное указание индекса данных для `x`
	- `valueShift:` значение
- `fixedScale`: значение
- `fitPanelWidth:` false/true
- `aspectRatio:` значение1:значение2
- `margin:` up, right,  down, left
- Поля и общие части:
	- `title:` название
	- 	 `yAxisLabel:` \[название1, \*название2]
	- `yAxisUnit:` \[название1, \*название2]
	- `yMin:` \[значение1, \*значениe2]
	- `yMax:` \[значение1, \*значение2]
	- `yAxisLocation:`  \[значение1, \*значение2] (bottom/right/left)
	- `yAxiscolor:`  \[цвет1, \*цвет 2]
		- `yAxisLabelColor:`  \[цвет1, \*цвет 2]
	- `yAxisTickInterval`: \[значение1, \*значение2] 
	-     `yAxisTickLabelFormat:` (`.`n`f` десятичная точность) | `YMDHm` (для времени, количество чёрточек изменяемо)
	- `yAxisPadding:` значение
	- `reverseYAxis:` false/true
	- 	 `showLegend:` false/true
	- `legendPosition:` bottom/right/left/top
	- `legendOrientation:` vertical/horizontal
- График. `line:`
	- `lineColor:` \[цвет1, \*цвет 2]
	- `lineWidth:` \[значение1, \*значение2]
	-     `showLine:` false/true
	-     `pointColor:` \[цвет1, \*цвет 2]
	- `pointBorderWidth:` \[значение1, \*значение2]
	- `pointBorderColor:` \[цвет1, \*цвет 2]
	- `showPoint`: false/true
- `bar:`
	-     `barColor:` \[цвет1, \*цвет2]
- `bullet:`
	- `orientation`: horizontal/vertical
	- `range:`  \[значение1, \*значение2] \[значение1, \*значение2]
	- `rangeColor:`\[цвет1, \*цвет2]
	- `value:` значение
	- `valueUnit:` значение
	-     `valueColor:` цвет
	- `showMarker:` false/true
	- `markerValue:` значение
	- `markerColor:` цвет
- `month:`
	- \*параметр `datasetName` в данных отвечает за заголовок
	- `dataset:` 0, 1… (явно говорим о наличии нескольких наборов данных) 
	-     `initMonth`: YYYY-MM или `-47M`
	-     `startWeekOn`: `'Mon'`/`'Sun'`
	- `threshold:` значение (порог)
	-     `thresholdType`: `LessThan`/`GreaterThan`
	- `dimNotInMonth:` false/true
	- `headerMonthColor`: цвет
	- `todayRingColor:` цвет
	-     `selectedRingColor:` цвет
	- `circleColorByValue:` false/true — дифференциация по значению (`yMin`, `yMax`)
	- `circleColorByStreak:` false/true
	-     `showSelectedValue:` false/true
	-     `mode: annotation`:
		- `annotation`: \[значение1, \*значение2]
		- `showAnnotationOfAllTargets`: false/true
- `pie:`
	- `label`: строка
	- `extLabel`: строка (используется, если `label` не вместилось)
	- `hideLabelLessThan`: значение
	- `showExtLabelOnlyIfNoLabel`: false/true
	- `data:`  \[значение1, \*значение2]
	- `dataColor:` \[цвет1, \*цвет 2]
	- `dataName:` \[значение1, \*значение2]
	- `ratioInnerRadius:` значение
- Формула:
	- `summary:`
		- `template:` "Строка {f-строка}"
		- К данным можно обращаться как `dataset(0)`
		- Функции оформляются в `{}`
		- Основные Функции:
			-    `average()`
			- `median()`
			- `max()`
			- `min()`
			- `sum()`
			- `maxDate()`
			- `minDate()`
			- `startDate()`
			- `endDate()`
			- `setMissingValues(dataset(0), value)`
			- `normalize()`
		- Модификаторы:
			- `::i` — целое число
			- `::.2f` — дробное число с двумя знаками
			- `::s` — строка
- Style:
	- `font-size:`n`px`
	- `color:`цвет
	- `margin:`n`px` (`top`, `bottom`, `left`, `right`)

Декоратор — это функция, которая принимает одну функцию в качестве аргумента и возвращает другую функцию.
Мануальное присвоение такой функции выглядит так:
```python
def document_it(func):  
    def new_function(*args, **kwargs):  
        print("Running function", func.__name__)  
        print("Positional arguments", args)  
        print("Keyword arguments", kwargs)  
        result = func(*args, **kwargs)  
        print("Result:", result)  
        return result  
    return new_function  
  
  
def pow(number, power=10):  
    return number**power  
  
a = document_it(pow)  
a(2, power=3)
"""
Running function pow
Positional arguments (2,)
Keyword arguments {'power': 3}
Result: 8
"""
```

Пример двух декораторов через `@`:
```python
def document_it(func):  
    def new_function(*args, **kwargs):  
        print("Running function", func.__name__)  
        print("Positional arguments", args)  
        print("Keyword arguments", kwargs)  
        result = func(*args, **kwargs)  
        print("Result:", result)  
        return result  
    return new_function  
  
def square_it(func):  
    def new_function(*args, **kwargs):  
        return func(*args, **kwargs) ** 2  
    return new_function  
  
@document_it  
@square_it  
def pow(number, power=10):  
    return number**power  
  
pow(2, power=3)
```

В Python все атрибуты открытые, но все-таки можно написать геттеры и сеттеры двумя разными способами. 

Первый:
```python
class Duck:  
    def __init__(self, input_name):  
        self.hidden_name = input_name  
    def get_name(self):  
        print("inside the getter")  
        return self.hidden_name  
    def set_name(self, input_name):  
        print("inside the setter")  
        self.hidden_name = input_name  
    name = property(get_name, set_name)  
  
  
duck = Duck("Jimmy")  
print(duck.name)  
duck.name = "Vlad"  
print(duck.name)
```

Второй:
```python
class Duck:  
    def __init__(self, input_name):  
        self.hidden_name = input_name  
    @property  
    def name(self):  
        print("inside the getter")  
        return self.hidden_name  
  
    @name.setter  
    def name(self, input_name):  
        print("inside the setter")  
        self.hidden_name = input_name  
  
duck = Duck("Jimmy")  
print(duck.name)  
duck.name = "Vlad"  
print(duck.name)
```

В первом случае мы можем обращаться на прямую к функции, а во втором это невозможно

(стр. 170)
Полиморфизм — одна операция может быть произведена над разными объектами независимо от их класса:
```python
class Quote():  
    def __init__(self, person, words):  
        self.person = person  
        self.words = words  
  
    def who(self):  
        return self.person  
  
    def says(self):  
        return self.words  
  
  
class QuestionQuote(Quote):  
    def says(self):  
        return self.words + "?"  
  
  
class ExclamationQuote(Quote):  
    def says(self):  
        return self.words + "!"  
  
  
class BabblingBrook:  
    def who(self):  
        return 'Brook'  
  
    def says(self):  
        return 'Babble'  
  
  
def who_says(obj):  
    print(f"{obj.who()}: {obj.says()}")  
  
  
who_says(ExclamationQuote("James", "Yep"))  
who_says(QuestionQuote("Fatima", "What"))  
who_says(BabblingBrook())
"""
James: Yep!
Fatima: What?
Brook: Babble
"""
```
Здесь `BabblingBrook` вообще не связан с `Quote`, но работает так же правильно

Именованный кортеж — это кортеж, к элементам которого можно получи доступ по имени или позиции.

Создаётся подобным образом:
```python
from collections import namedtuple  
  
Duck = namedtuple('Duck', 'bill tail')  
duck = Duck('white', 'long')  
#Определение через словарь  
parts = {'bill': 'white', 'tail': 'long'}  
duck = Duck(**parts)  
print(duck.bill) #white  
print(duck.tail) #long
```

Плюсы использования:
- Они действуют как неизменяемый объект
- Они более эффективны, чем объекты

Обработка данных. Текст
^TextAnalysis
Для работы с текстом в Python можно использовать символы unicode.
Их можно вызвать с помощью управляющей последовательности `\u` или `\U` или же подключить библиотеку `unicodedata` 
```python
import unicodedata
unicodedata.name("д")
#'CYRILLIC SMALL LETTER DE'
unicodedata.lookup('CYRILLIC SMALL LETTER DE')
#'д'
```

>[!warning]
>Имена, перечисленные в списке Unicode Character Name Index, были переформатирова-
ны для удобства отображения. Для того чтобы преобразовать их в настоящие имена сим
волов Unicode (которые используются в Python), удалите запятую и переместите ту часть
имени, которая находится после нее, в самое начало. Соответственно, в нашем примере
E WITH ACUTE, LATIN SMALL LETTER нужно изменить на LATIN SMALL LETTER E WITH
ACUTE

Для кодирования и декодирования используются методы строки `encode` и `decode` с указанием кодировки. Второй также может принимать параметры `strict` (исключение), `ignore` (игнорирование), `replace` (?), `backslachreplace` (код через `\\`) и `xmlcharrefreplace` для неизвестных символов

Лучше кодировать информацию в utf-8
>[!info]
>UTF-8 автоматически выделяет место под разные языки. Так, ASCII содержится в одном байте, многие языки на латинице в двух, кириллица и другие простые языки в трех, а сложные языки в четыре

```
"Привет, мир!".encode("utf-8")
#b'\xd0\x9f\xd1\x80\xd0\xb8\xd0\xb2\xd0\xb5\xd1\x82, \xd0\xbc\xd0\xb8\xd1\x80!'
b'\xd0\x9f\xd1\x80\xd0\xb8\xd0\xb2\xd0\xb5\xd1\x82, \xd0\xbc\xd0\xb8\xd1\x80!'.decode("utf-8")
#'Привет, мир!'
```

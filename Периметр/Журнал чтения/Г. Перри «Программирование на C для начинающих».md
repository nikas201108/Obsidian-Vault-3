(стр. 24)
Первая программа  из разряда «Hello World»:
```c
#include <stdio.h>
main()
{
	printf("Just one small step for coders. One giant leap for");
	printf(" programmers!\n");
	return 0;
}
```

^SimplestProgramm

Здесь надо обратить внимание на:
- Функция `main` — это главная функция, с которой всегда начинается выполнения кода в Си. Её желательно размещать наверху 
- `#include <stdio.h>` — это импорт функций для ввода/вывода

(стр. 30)
Основные типы данных:
- Символы. Любой отдельный символ, отображаемый компьютером и содержащейся в том числе в таблице ASCII. Заключаются в одинарные кавычки 
- Строки. Совокупность символов. Заключаются в двойные кавычки
- Целые числа. Дробный разделитель отсутствует (в нашем случае точка)
- Числа с плавающей точкой. Дробный разделитель присутствует. Занимают больше памяти

^TypesOfData

(стр. 48)
Необходимо учитывать, что в Cи не предусмотрен стандартный перевод курсора на следующую строку. Для этого необходимо вручную вводить управляющую последовательность.

| Код  | Описание                       |
| ---- | ------------------------------ |
| `\n` | новая строка                   |
| `\a` | звуковое оповещение            |
| `\b` | возврат каретки на один символ |
| `\t` | табуляция                      |
| `\\` | вывод обратного слэша          |
| `\'` | вывод апострафа                |
| `\"` | вывод двойной кавычки          |
Пример:
```c
#include <stdio.h>
main ()
{
	printf("Column A\tColumn B\t Column C");
	printf("\nMy Computer\'s Beep Sounds Like This: \a!\n");
	printf("\"Letz\bs fix that typo and then show the backslash ");
	printf("character \\\" she said \n");
	return 0;
}
```

Команды `#include` и `#define` являются *директивами предпроцессора*, которые не влияют на ход программы после запуска, но работают во время компиляции

(стр. 76)
`#include` — это просо программа, которая ищет в папке указанный файл и включает код из него в файл, из которого она вызвана. Имеет два стиля оформления:
- `#include <>` — ищет в стандартной папке с файлами
- `#include ""` — ищет сначала в папке, из которой произошел вызов, а потом в стандартной папке с файлами

(стр. 150)
Цикл `while`:
```c
while (условие)
{блок из одного или нескольих выражений;}
```
Выполнение цикла тела цикла продолжается до тех пор, пока условие верно. В случае while надо всегда добавлять скобки (так как очень редко мы сталкиваемся с while с только одним выражением)

Пример счётчика:
```c
#include <stdio.h>

main(){
	int counter = 0;
	while (counter < 5){
		counter++;
		printf("%d %s", counter, (counter == 5) ? "" : "\n");
	} 
}
```

(стр. 153)
Цикл `do…while`:
```c
do
{блок из одного или нескольких выражений;}
while (условие)
```
Этот цикл, как `while`, но условие проверяется в конце, а значит цикл выполниться хотя бы один раз

(стр. 157)
цикл `for` позволяет указать конкретное количество повторений цикла:
```c
#include <stdio.h>

main() {
	int ctr;
	for (ctr = 1; ctr <= 5; ctr++) {
		printf("Value: %d\n", ctr);
	}
}
```

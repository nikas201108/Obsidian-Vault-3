

|                  | k                                 |
| ---------------- | --------------------------------- |
| Последовательное | $k=\dfrac{k_1\cdot k_2}{k_1+k_2}$ |
| Параллельное     | $k=k_1+k_2$                       |


## Последовательное 

![[Соединения пружин — медиа 1.png]]
Чтобы понять, откуда получается формула $k$ для последовательного соединения, скажем, что $\Delta x = \Delta x_1 + \Delta x_2$. Кроме того, $F_1=F_2=F$

Тогда: $$\begin{align}&\frac{F}k=\frac{F_1}{k_1}+\frac{F_2}{k_2}\\\\&\frac{1}{k}=\frac1{k_1}+\frac{1}{k_2}\\\\&k=\frac{k_2+k_1}{k_1\cdot k_2}\end{align}$$

## Параллельное
![[Соединения пружин — медиа 2.png]]
Для обоснования формулы скажем, что $\Delta x = \Delta x_1 = \Delta x_2$
Тогда: $$\begin{align}&k\Delta x = k_1\Delta x_1 + k_2\Delta x_2\\\\&k=k_1+k_2\end{align}$$

>[!term]+ Определение
>Алгоритм Евклида — это алгоритм для эффективного нахождение НОД чисел. Основывается исключительно на [[НОД И НОК#Свойства|его]] свойствах 

# Через деление
>[!term]+ Алгоритм
>1. Сначала большее из двух чисел делим на меньшее
2. Если деление произошло без остатка, то меньшее из чисел и есть НОД
3. Если имеется остаток, то большее из чисел заменяем на этот остаток
4. Переходим к первому пункту


>[!code]- Реализация на Python
>```python
>def gcd_r(a, b):
>	if b == 0: return max(a, b)
>	return gcd_r(b, a % b)
>  
>def gcd_i(a, b):
>	if b == 0 or a == 0: return max(a, b)
>	while b:
>		a, b = b, a%b
>	return a
>```


# Через вычитание
>[!term]+ Алгоритм
>1. Сначала вычитаем из большего числа меньшее
>2. Если получаем нуль, то числа равны друг другу и являются НОД
>3. Если результат отличен от нуля, то большее число заменяем на результат вычитания
>4. Возвращаемся к первому пункту, пока не получим нуль

>[!code]- Реализация на Python
>```python
>def gcd_r(a, b):
>    if b == 0: return a
>   if a > b:
>        return gcd_r(a - b, b)
>    else:
>        return gcd_r(a, b - a)
>
>def gcd_i(a, b):
>    if b == 0 or a == 0: return max(a, b)
>    while a != b:
>        if a > b:
>            a -= b
>        else:
>            b -= a
>    return a
>```

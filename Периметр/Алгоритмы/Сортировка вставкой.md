>[!point]- Суть алгоритма
>Совершаем проход по массиву, начиная со второго элемента, и каждый новый элемент под индексом `i` определяем на место в отсортированном массиве `[1, i-1]` с помощью цикла `while` и оператора присвоения
>![[Pasted image 20251012221500.png]] 

>[!code]- Реализация на Python
>>[!multi-column]
>>>```Python
>>>def insertion_sort(arr):  
>>>    for i in range(1, len(arr)):  
>>>        key = arr[i]  
>>>        j = i - 1  
>>>        while j >= 0 and arr[j] > key:  
>>>            arr[j+1] = arr[j]  
>>>            j -= 1  
>>>        arr[j+1] = key  
>>>    return arr```

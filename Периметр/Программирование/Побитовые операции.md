
| Оператор | Значение                  |
| -------- | ------------------------- |
| &        | Побитовое и               |
| \|       | Побитовое или             |
| ^        | Побитовое исключающее или |
| ~        | Побитовая инверсия        |
| <<       | Побитовый сдвиг влево     |
| >>       | Побитовые сдвиг вправо    |
`bit_length` это функция, которая позволяет определить разрядность любого числа в двоичной форме:
```python
(42).bit_length()
```

## Математические представления побитовых операций

| Операция | Математическое представление | Комменатарий              |
| -------- | ---------------------------- | ------------------------- |
| &        | $a_i \times b_i$             | И то, и то                |
| \|       | $a_i - b_i + (a_i\cdot b_i)$ | Или то, или то            |
| ^        | $a_i+b_i \mod 2$             | Выбор обязательный и один |


## Различие логического и арифметического сдвигов
Арифметический сдвиг сдвигает число, реплецируя знак вправо (по факту сохраняет его):$$1010\to1101$$
Логический сдвиг же просто добавляет $0$ и в любом случае делает число неотрицательным: $$1010\to 0101$$ 
В Python нет логического сдвига, так как в Python число представлено бесконечным количеством битов

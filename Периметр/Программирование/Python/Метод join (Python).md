Функция join позволяет объединить любой итерируемый объект с помощью указателя

```python
vowels = ["a", "e", "i", "o", "u"]
vowels_str = ",".join(vowels)
print(vowels_str) #a,e,i,o,u
```

Она может использоваться:
- Когда необходимо преобразовать список в строку (пример выше)
- Когда необходимо преобразовать строку, добавив разделители
  ```python
  name = "John"
  print(" ".join(name)) #J o h n
	```

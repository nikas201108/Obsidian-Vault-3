format — это строковый метод, который форматирует строку в Python

Он работает на основе:
- Позиционных аргументов
```python
string = "Hello, {0}! Do you like {1}?".format("Adam", "appples")  
print(string) # Hello, Adam! Do you like appples?
```
- По ключевым словам
```python
string = "Hello, {name}! Do you like {food}?".format(name="Adam", food="appples")  
print(string)
```

## Форматирование чисел
Форматирование строк происходит подобным образом:
```python
print("The number is: {:0}".format(123)) #The number is: 173
```


| Тип |            Значение             |     |
| --- | :-----------------------------: | --- |
| d   |           целое число           |     |
| c   |         символ Unicode          |     |
| b   |         двоичный формат         |     |
| o   |       восьмеричный формат       |     |
| x   |  шестнадцатеричный формат (a)   |     |
| X   |  шестнадцатеричный формат (A)   |     |
| n   |  как d, на с разделением числа  |     |
| e   |   экспоненциальная запись (e)   |     |
| E   |   экспоненциальная запись (E)   |     |
| f   | фиксированное количество знаков |     |
| F   |       как f, но INF и NAN       |     |
| g   |  общий формат, округление до p  |     |
| G   | как G, но с экспонентой иногда  |     |
| %   |            проценты             |     |

- Запись `:.0(n)f` округляет  дробное число до `n`
```python
print("The number is: {:.3f}".format(0.555555)) #The number is: 0.556
```
- Запись `:3d` обеспечивает отступ, когда число недостаточно большое:
```python
print("The number is: {:3d}".format(54)) The number is:  54
```
- Запись `:03df` обеспечивает заполнение нулями, когда число недостаточно большое:
```python
print("The number is: {:03d}".format(54)) #The number is: 054
```
- Можно добавить `+` (отображение всех знаков числа), `-` (отображение минусов у отрицательных чисел), `: d` (пробел вместо положительного числа и минус у отрицательного)


| Тип | Значение                     |     |
| --- | ---------------------------- | --- |
| <   | по левому краю               |     |
| ^   | по центру                    |     |
| >   | по правому краю              |     |
| =   | сдвиг знаков к левой позиции |     |


## Некоторые плюшки и неочевидные реализации

### Список вида element1, element2, element3, …, element(n-1) and element(n)
Это можно достичь с помощью срезов и функции `join`:
```python
names = ["John", "Herman", "Willy", "Karl", "Jeremy"]
print(", ".join(names[:-1]) + " and " + names[-1])
```

### Добавление символов при определенном условии через format
```python
plural = True
print("dog{}".format("s" if plural == True else ""))
```

#Python

Работает очень просто: принимает в качестве аргументов две последовательности, а на выходе выдаёт последовательность с двумя элементами, где первый элемент — элемент первой последовательности, а второй — элемент второй последовательности с тем же индексом

```python
print(list(zip("Hello", "World"))) #[('H', 'W'), ('e', 'o'), ('l', 'r'), ('l', 'l'), ('o', 'd')]
```

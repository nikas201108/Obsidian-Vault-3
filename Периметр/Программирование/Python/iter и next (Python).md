Можно получить итератор и идти по нему с помощью метода next():
```python
>>> a = (1, 2, 3, 4, 5, 6)
>>> m = iter(a)
>>> next(m)
>>> 1
>>> next(m)
>>> 2
>>> next(m)
>>> 3
>>> next(m)
>>> 4
>>> next(m)
>>> 5
>>> 
```

В своих классах реализовывается с помощью `__iter__` (инициализация) и `__next__` (непосредственно вызов)

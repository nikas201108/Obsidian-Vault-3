reduce — это функция, которая принимает другую функции и применяет её к итерируемому объекту, сводя его к единственному значению. Последним идёт объект стартового отсчёта

Библиотека functools

Проще показать пример её применения в случае факториала:
```python
reduce(lambda x, y: y*x, range(1, 6), 1)
```

Это будет выглядеть как: (((((1 * 1) * 2) * 3) * 4) * 5)

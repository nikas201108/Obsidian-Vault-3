>[!task] 
>Написать класс, который содержит в себе функции, которые пользователь может удалять и добавлять, вызывать.

-----------
## Решения
##### Решение 
```python
class Event():
    
    def __init__(self):
        self.handlers = set()
    
    def subscribe(self, func):
        self.handlers.add(func)
    
    def unsubscribe(self, func):
        self.handlers.remove(func)
    
    def emit(self, *args):
        map(lambda f: f(*args), self.handlers)
```

**Ваша задача:** алгоритм должен принимать на вход номиналы монет и сумму для сдачи, и выводить минимальное количество монет, необходимое для сдачи.
>У вас есть набор монет с разными номиналами (например, 1, 5, 10, 25 центов) и вам нужно сдать монеты на определенную сумму денег (например, 37 центов). Ваша задача - найти минимальное количество монет, необходимое для сдачи.
>
>**Ограничения:**
>
> - У вас есть неограниченное количество каждой монеты с определенным номиналом.
>
>**Пример:**
>
> - Номиналы монет: 1, 5, 10, 25 центов
> - Сумма для сдачи: 37 центов
> - Решение: 25 центов + 10 центов + 1 цент + 1 цент (4 монеты)

-------------

## Решения 

Чтобы решить эту задачу надо использовать жадный алгоритм, который через локально-оптимальные решения получит глобально-оптимальное  решение: мы будем вычитать максимально возможный номинал из сдачи на каждой итерации.

```python
from collections import Counter  
  
denominations = (1, 5, 10, 25)  
  
denominations_used = Counter()  
change = int(input())  
  
while change > 0:  
    best_choice = denominations[0]  
    for x in denominations:  
        if (change - best_choice) > (change - x) >= 0:  
            best_choice = x  
    denominations_used[str(best_choice)] += 1  
    change -= best_choice  
  
  
print(denominations_used.total())
```

Для подсчета будет использовать класс Counter

>[!task] 
>Complete the function/method (depending on the language) to return `true`/`True` when its argument is an array that has the same nesting structures and same corresponding length of nested arrays as the first array.

-----------
## Решения
##### Решение 1. Создание шаблона через прохождение по массиву
Суть в том, что мы раскрываем в общем виде все вложенные списки под разными буквами.

```python
from collections import deque  
  
  
def same_structure_as(original, other):  
    if type(original) == type(other) == list:  
        return create_scheme(original) == create_scheme(other)  
    else:  
        return False  
  
  
def create_scheme(array):  
    list_array = deque()  
    structure = []  
    letter_count = 0  
  
    for x in array:  
        if type(x) == list:  
            list_array.append(x)  
            structure.append("l")  
        else:  
            structure.append("n")  
  
    while list_array:  
        element = list_array.popleft()  
        start_pos = structure.index('l')  
        structure[start_pos] = None  
        for x in range(len(element)):  
            if type(element[x]) == list:  
                list_array.appendleft(element[x])  
                structure.insert(start_pos + x, "l")  
            else:  
                structure.insert(start_pos + x, chr(65 + letter_count))  
        letter_count += 1  
    return structure
```

Функция `create_scheme` выдает такой результат на `[0, [1, 1, [0]], [4], 9, 4]`: `['n', 'A', 'A', 'B', None, None, 'C', None, 'n', 'n']`. Соответственно схемы должны совпадать, чтобы мы могли говорить о совпадении структур массивов

##### Решение 2. Гениальное по праву

```python
def same_structure_as(original,other):  
    if isinstance(original, list) and isinstance(other, list) and len(original) == len(other):  
        for o1, o2 in zip(original, other):  
            if not same_structure_as(o1, o2): return False  
        else: return True  
    else: return not isinstance(original, list) and not isinstance(other, list)  
```

Давайте скажем, что нам в целом все равно на содержимое массива. Нас будут волновать только списки, находящиеся внутри, так как они могут различаться наполнением. Стоит сказать, что `original` и `other` являются не только объектами класса `list`. 

Когда они впервые попадают в программу, то они всегда будут `list` из условия задачи. Поэтому в начале роль будет играть только их длинна. Если она будет разнится, то мы получим `False`, так как `and` объединит `False` и `False`.

Если все-таки длина у них одинаковая, то с помощью функции `zip` мы соотнесем каждый элемент массива с другим элементом другого массива и начнём их разбирать с помощью рекурсии:
- Если они будут оба списками с одинаковой длиной, то рекурсия углубится.
- Если один из объектов будет списком, то получим `False` из-за `False and False`
- Если они оба не списки, то получим `True`

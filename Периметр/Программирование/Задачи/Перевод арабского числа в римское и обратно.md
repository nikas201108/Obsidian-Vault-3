>[!task]
>Write two functions that convert a roman numeral to and from an integer value. Multiple roman numeral values will be tested for each function.
>
>Modern Roman numerals are written by expressing each digit separately starting with the left most digit and skipping any digit with a value of zero. In Roman numerals:
>
>- `1990` is rendered: `1000`=`M`, `900`=`CM`, `90`=`XC`; resulting in `MCMXC`
>- `2008` is written as `2000`=`MM`, `8`=`VIII`; or `MMVIII`
>- `1666` uses each Roman symbol in descending order: `MDCLXVI`.
>
>I nput range : `1 <= n < 4000`
>
>In this kata `4` should be represented as `IV`, NOT as `IIII` (the "watchmaker's four").
>
> ### Examples
>
>```
>to roman:
>2000 -> "MM"
>1666 -> "MDCLXVI"
  >86 -> "LXXXVI"
   >1 -> "I"
>
>from roman:
>"MM"      -> 2000
>"MDCLXVI" -> 1666
>"LXXXVI"  ->   86
>"I"       ->    1
>```
>
>### Help
>
>```
>+--------+-------+
>| Symbol | Value |
>+--------+-------+
>|    M   |  1000 |
>|   CM   |   900 |
>|    D   |   500 |
>|   CD   |   400 |
>|    C   |   100 |
>|   XC   |    90 |
>|    L   |    50 |
>|   XL   |    40 |
>|    X   |    10 |
>|   IX   |     9 |
>|    V   |     5 |
>|   IV   |     4 |
>|    I   |     1 |
>+--------+-------+
>```

## Решения
##### Решение 
Мое решение по сути своей представляет из себя в случае перевода из арабское в римское жадный алгоритм.
```python
class RomanNumerals:  
    global numbers  
    numbers = dict(M = 1000, CM = 900, D = 500, CD = 400, C = 100, XC = 90, L = 50, XL = 40, X = 10, IX = 9, V = 5, IV = 4, I = 1, Null=0)  
  
    @staticmethod  
    def to_roman(val: int) -> str:  
        scheme = [val // 10 ** x % 10 for x in range(3)] + [val // 1000]  
        dec_sequence = []  
        for i in range(len(scheme)):  
            number = scheme[i] * (10 ** i)  
            best_choice = 0  
            while number > 0:  
                for el in numbers.values():  
                    if number - best_choice > number - el >= 0:  
                        dec_sequence.append(el)  
                        number -= el  
                        best_choice = 0  
                        break  
        dec_sequence = sorted(dec_sequence[::-1], reverse=True)  
        converted_sequence = []  
        for x in dec_sequence:  
            for key in numbers.keys():  
                if numbers[key] == x:  
                    converted_sequence.append(key)  
        return "".join(converted_sequence)  
  
    @staticmethod  
    def from_roman(roman_num: str) -> int:  
        result = 0  
        roman_num = list(roman_num)  
        for x in range(len(roman_num)):  
            try:  
                if "{}{}".format(roman_num[x], roman_num[x+1]) in numbers.keys():  
                    result += numbers["{}{}".format(roman_num[x], roman_num[x+1])]  
                    roman_num[x+1] = "Null"  
                else:  
                    result += numbers[roman_num[x]]  
            except:  
                result += numbers[roman_num[x]]  
        return result
```

> Найти кубический корень числа с точность `accuracy` с помощью бинарного поиска

-------------

### Решение
В данном случае, так как кубический корень является монотонно-возрастающей функцией, то можно найти кубический корень с помощью бинарного поиска. 

Так, если мы ищем значение $y_e = \sqrt[3]{x_e}$, то нам достаточно указать начальные рамки, а потом начать сдвигать их, ведь $x_e < x \to y_e < y$ и наоборот.

```python

x = int(input())  
accuracy = int(input())  
  
def find_cube_root(x, accuracy=1):  
    lowest_border = -50  
    highest_border = 50  
    average = (lowest_border + highest_border) / 2  
    while abs(x - average**3) > 10**(-accuracy):  
        if x < average ** 3:  
            highest_border = average  
        else:  
            lowest_border = average  
        average = (lowest_border + highest_border) / 2  
        print(x - average**3)  
    return round(average, accuracy)  
  
  
print(find_cube_root(x, accuracy))
```

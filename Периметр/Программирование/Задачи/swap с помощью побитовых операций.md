>[!task] 
>Задача: Напишите функцию `swap(a, b)`, которая принимает два положительных целых числа `a` и `b` и меняет местами их значения без использования дополнительной переменной. Функция должна вернуть кортеж из двух поменянных чисел.
>
>Условия:
>
>- `a` и `b` - положительные целые числа
>- не использовать дополнительную переменную
>- использовать побитовые операции
>
>Подсказка: можно использовать операцию XOR (`^`) для этого.
>
>Пример:
>
>```
>>> swap(5, 10)
(10, 5)
>>> swap(3, 7)
(7, 3)
>```

-----------
## Решения
##### Решение 
Так как операция XOR обладает свойством: `a^b^b = a`, то можно построить решение на нём:
```python
def swap(a:int, b:int) -> tuple:  
    """swap() fuction swaps given elements  
    a should be positive or zero    b should be positive or zero    output is tuple with swapped values  
    example:    print(swap(46, 0)) -->> (o, 46)    """    if a < 0 and b < 0:  
        raise ValueError  
    return a ^ b ^ a, a ^ b ^ b
```

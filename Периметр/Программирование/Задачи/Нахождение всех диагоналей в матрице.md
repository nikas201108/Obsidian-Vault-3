>Найти в матрице размером $n\cdot n$  все возможные диагонали и вывести их


-----------
## Решения
По сути своей, идя по диагонали матрицы, мы всегда уменьшаем на шаг `row` или `column`, а другой параметр на шаг увеличиваем. Так можно получить любую диагональ
##### Решение 
```python
def get_uldr_diagonal(array):  
    total1 = []  
    total2 = []  
    total3 = []  
    total4 = []  
    total5 = []  
    for column in range(len(array)-1):  
        for row in range(column + 1):  
            total1.append(array[column-row][row])  
        for row in range(column + 1):  
            total2.append(array[len(array)-1-column+row][len(array)-1-row])  
        for column in range(len(array) - 1):  
            for row in range(column + 1):  
                total3.append(array[len(array)-1 - column + row][row])  
            for row in range(column + 1):  
                total4.append(array[column - row][len(array)-1 - row])  
        for row in range(len(array)):  
            total5.append(array[len(array)-1 - row][row])  
    for row in range(len(array)):  
        total5.append(array[row][row])  
    return total1, total2, total3, total4
```

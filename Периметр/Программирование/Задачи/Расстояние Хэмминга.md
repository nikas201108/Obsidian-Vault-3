Расстояние Хэмминга (кодовое расстояние) — число позиций, в которых соответствующие символы двух слов одинаковой длины различны. В общем случае метрика различия объектов одинаковой размерности.

Формула в общем случае такая:
$$d_{ij}=\sum^p_{k=1}|x_{ik}-x_{jk}|$$
Примеры:
- $d(101, 111) = 1$
- $d(\textup{toned}, \textup{roses}) = 3$ 

Свойства:
- $d(x, y) = 0 \Leftrightarrow x = y$ (аксиома тождества)
- $d(x, y) = d(y, x)$ (аксиома симметричности)
- $d(x, z) \leqslant d(x, y) + d(y, z)$ (аксиома треугольника)

Реализация расстояния Хэмминга для слов на Python:
```python
def hamming(a,b):
  return sum(ch1 != ch2 for ch1, ch2 in zip(a, b))
```

#Python 

>[!task] 
>Take the following IPv4 address: `128.32.10.1`
>
>This address has 4 octets where each octet is a single byte (or 8 bits).
>
>- 1st octet `128` has the binary representation: `10000000`
>- 2nd octet `32` has the binary representation: `00100000`
>- 3rd octet `10` has the binary representation: `00001010`
>- 4th octet `1` has the binary representation: `00000001`
>
>So `128.32.10.1` == `10000000.00100000.00001010.00000001`
>
>Because the above IP address has 32 bits, we can represent it as the unsigned 32 bit number: `2149583361`
>
>Complete the function that takes an unsigned 32 bit number and returns a string representation of its IPv4 address.
>
> ## Examples
> 
> ```
>2149583361 ==> "128.32.10.1"
>32         ==> "0.0.0.32"
>0          ==> "0.0.0.0"
>```

------
## Решения 

#### Подход первый.  Использование формат и строк
В какой-то степени скучный подход: мы просто представляем число в двоичном виде, а потом делим на байты уже в десятичном виде. Все объединяется в итоге с помощью `.join()`

```python
def int32_to_ip(int32):
    binary = "{:032b}".format(int32)
    binary_scheme = [str(int(binary[8*i:8+8*i], 2)) for i in range(4)]
    return ".".join(binary_scheme)
```

#### Подход второй. Использование побитовых операций и масок
Код вот такой:
```python
def int32_to_ip(int32):
	first = (int32 & (255 << 24)) >> 24  
	print("{:b}".format(int32 & (255 << 8)))  
	second = (int32 & (255 << 16)) >> 16  
	third = (int32 & (255 << 8)) >> 8  
	fourth = int32 & 255  
	return f"{first}.{second}.{third}.{fourth}"
```

Суть достаточно проста, если только вдуматься: здесь `&` обозначает побитовую операцию И. В свою очередь стрелочки — это сдвиг по битам: например число `101 << 2` превратиться в `10100`. Так вот, мы создаем маску заполненную единицами, сдвигаем её в нужный разряд и тем самым получаем число.

Возьмем `int32 = 148 322`

|     |  4 байт  |     |  3 байт  |     |  2 байт  |     |  1 байт  |     |
| :-: | :------: | --- | :------: | --- | :------: | --- | :------: | --- |
|     | 00000000 |     | 00000010 |     | 01000011 |     | 01100010 |     |

Теперь посмотрим на маску `255 << 24`

|     |  4 байт  |     |  3 байт  |     |  2 байт  |     |  1 байт  |     |
| :-: | :------: | --- | :------: | --- | :------: | --- | :------: | --- |
|     | 11111111 |     | 00000000 |     | 00000000 |     | 00000000 |     |
А теперь давайте применим операцию `&` (побитовое и)

|     |  4 байт  |     |  3 байт  |     |  2 байт  |     |  1 байт  |     |
| :-: | :------: | --- | :------: | --- | :------: | --- | :------: | --- |
|     | 00000000 |     | 00000000 |     | 00000000 |     | 00000000 |     |

Сдвигая обратно, мы получим десятичное число `0`.

По такому же принципу рассмотрим маску `255 << 8`

|     |  4 байт  |     |  3 байт  |     |  2 байт  |     |  1 байт  |     |
| :-: | :------: | --- | :------: | --- | :------: | --- | :------: | --- |
|     | 00000000 |     | 00000000 |     | 11111111 |     | 00000000 |     |

Применив побитовое и получим:

|     |  4 байт  |     |  3 байт  |     |  2 байт  |     |  1 байт  |     |
| :-: | :------: | --- | :------: | --- | :------: | --- | :------: | --- |
|     | 00000000 |     | 00000000 |     | 01000011 |     | 00000000 |     |
Переводя в десятичную систему счисления: 67

Информация — сведения об окружающем мире, которые человек получает и обрабатывает разными путями; отражает реальный мир

Информатика:
- Теоретическая информатика
- Вычислительная техника
- Алгоритмизация и программирование
- Прикладная информатика
- Искусственный интеллект

Прикладная информатика связана с прикладным ПО:
- Системное ПО связано с операционными системами и серверными приложениями
- Обобщенного назначения (графические редакторы, мультимедийные проигрыватели, текстовые процессоры)
- Специального назначения (MathCad, 1C)

Программа — алгоритм, записанный на языке программирования

Способы получения информации:
- Зрительная 
- Звуковая 
- Вкусовая 
- Обонятельная 
- Тактильная

Формы представления информации:
- Текстовая 
- Числовая
- Графическая 
- Звуковая 
- Мультимедийная 

Свойства информации:
- Объективность
- Понятность
- Полнота
- Достоверность 
- Полезность 
- Актуальность

Знания — представление человека о природе, подразделяющиеся  на декларативные (факты, знания) и процедурные (алгоритмы)

Данные — закодированная в некоторой форме информация на носителе

Информационные процесс — изменение свойства носителя. 
Можно выделить:
- Передача
- Обработка

Сигнал — изменение свойств носителя для передачи информации. Подразделяется на непрерывный и дискретный 

Обработка информации:
- Создание
- Кодирование
- Поиск
- Структурирование
- Сортировка

Количество информации определяется длиной сообщения. 
Двоичный код — содержащий два знака код

Формула Хартли: $i = log_2N$ (количество информации, содержащейся в сообщении в одном из $N$ возможных исходов события)


Структурирование — выделение важных элементов в информационном сообщения и установление связей между ними

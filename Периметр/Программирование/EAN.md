EAN — международный артикул (ранее европейский номер товара), стандарт, описывающий символику штрихкода, используемого в мировой торговле для идентификации товаров.![[EAN — медиа 1.png]]

Некоторые виды:
- EAN-5 и EAN-5 — дополнительные штрих-коды, размещаемые справа от EAN-8
- EAN-8 — сокращенный формат
- EAN-13 — самый распространенный формат
- EAN-128 — расширенный формат

## EAN-13
### Цифры
Первые три цифры кода отвечают за страну, к который присоединился производитель товара. Соответствует префиксу [GS1](https://en.wikipedia.org/wiki/List_of_GS1_country_codes)

Далее идёт код производителя, который может быть разным по длине. Присваивается организацией, которая работает в регионе, к которому присоединился производитель. Разный он из-за того, что разные производители выпускают разное количество товара: производителям с маленьким ассортиментом присваивается более длинный код, урезая код товара, и наоборот.

Код товара поэтому тоже переменчив.

Контрольная цифра используется для проверки правильности сканирования штрих-кода. Сумма всех цифр, умноженная на позицию (последняя цифра имеет вес 3, а контрольная вес 1; чередование), должна быть кратна 10. В примере выше при таком подходе сумма цифр равна 83, значит надо прибавить 7 (она стоит в конце)

### Штрих-код
Теперь необходимо перевести эти цифры в читаемый сканером формат.
Штрих-код состоит из 95 областей одинаковой ширины.

Здесь:
- 3 области для начальной отметки (101)
- 42 области по семь на каждую цифру для кодирования цифр 2–7 и косвенного кодирования цифры номер 1
- 5 областей для центрального маркера (01010)
- 42 области для кодирования цифр 8–13
- 3 области для конечного маркера (101)
  
![[Media/EAN — медиа 2.png]]

Каждая цифра первой группы (от 2 до 7) может быть закодирована двумя способами: чётным и нечётным. Это будет определять первую цифру, которая задается косвенно

| Первая цифра | Первая группа из 6 цифр |
| ------------ | ----------------------- |
| 0            | LLLLLL                  |
| 1            | LLGLGG                  |
| 2            | LLGGLG                  |
| 3            | LLGGGL                  |
| 4            | LGLLGG                  |
| 5            | LGGLLG                  |
| 6            | LGGGLL                  |
| 7            | LGLGLG                  |
| 8            | LGLGGL                  |
| 9            | LGGLGL                  |
Цифры второй группы всегда R, а первая цифра первой группы нечётна (L). Это позволяет сканировать код слева направо и наоборот.

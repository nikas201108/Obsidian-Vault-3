**Кластеризация** — это разделение множества входных векторов на группы (кластеры) по степени «схожести» друг на друга.

Применение кластерного анализа в общем виде сводится к следующим этапам:
1. Отбор выборки объектов для кластеризации.
2. Определение множества переменных, по которым будут оцениваться объекты в выборке. При необходимости – нормализация значений переменных.
3. Вычисление значений меры сходства между объектами.
4. Применение метода кластерного анализа для создания групп сходных объектов (кластеров).
5. Представление результатов анализа.

Классификация алгоритмов:
- Иерархические (нисходящие и восходящие) и плоские
- Четкие (каждый объект только одному кластеру) и нечеткие (вероятность)
## Работа с данными
Изначально необходимо определить значения, которые интересуют нас в задаче сравнения объектов. После этого их можно привести к определенному диапазону, например $[-1;1]$ или $[0;1]$, чтобы каждый объект вносил равный вклад при расчете расстояния 

## Расстояния

| Название          | Описание                                                                     | Формула                                                 |
| ----------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------- |
| Евклидово         | Представляет собой расстояние в в многомерном пространстве                   | $$p(x, x') = \sqrt{\sum_i^n(x_i-x_i)^2}\phantom{1111}$$ |
| Квадрат Евклидова | Из-за возведения в квадрат разница отличающимися объектами больше            | $$p(x, x') = \sum_i^n(x_i-x_i)^2\phantom{1111}$$        |
| Манхэттенское     | Разности между координатами. Влияния отдельных факторов разброса уменьшается | $$p(x, x') = \sum_i^n\|x_i-x_i\|\phantom{1111}$$        |
| Чебышева          | Объекты различны, если различаются по какой-нибудь координате                | $$p(x, x') = max(\|x_i-x_i\|)\phantom{1111}$$           |
| Степенное         | Евклидовое, но с произвольной степенью                                       |                                                         |

## Объединения кластеров
Вычислить расстояния между кластерами можно так:
- Одиночная связь (расстояние между ближайшими соседями)
- Полная связь (расстояние между наиболее отдаленными соседями). Если кластеры имеют удлиненную форму или строятся в цепочки, то это не подпадает под случай применения этого расстояния
- Невзвешенное попарное среднее. Среднее между всеми парами объектов
- Взвешенное попарное среднее. Размер кластера используется в качестве весового коэффициента
- Невзвешенный центроидный метод. Расстояние между центрами
- Взвешенный центроидный метод (медиана)

## k-means

>[!info]
>Есть заранее установленное число кластеров $k$. Алгоритм старается минимизировать среднеквадратичное отклонение на точках каждого кластера или же каждый кластер в течение множества итераций перевычисляет свой центр масс, после чего вектора снова разбираются по кластерам

$$e^2(X, L) = \sum_j^K\sum_i^{n_j}|x^{j}_i-c_j|$$

Алгоритм:
1. Случайно выбрать $k$ точек или центры масс кластеров
2. Отнести каждый объект к кластеру
3. Пересчитать центры масс
4. Продолжать в том же духе

Относится к алгоритмам квадратичной ошибки

| Достоинства    | Недостатки                                                                                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| - Простота<br> | - Необходимо заранее знать число кластеров<br>- Объект должен принадлежать к одному и только к одному кластеру<br>- Погрешность из-за случайного выбора центра первых кластеров |

## c-means

>[!info]
>Похож на $k$-means, но определяет вероятность попадания в тот или иной кластер

Алгоритм:
1. Создание матрицы принадлежности $U$ размера $n\times k$
2. Вычисление центров кластеров: $$c_k=\sum_{i=1}^NU_ix_i$$
3. Вычисляем ошибку $$E^2(X, U) = \sum_{i=1}^{N} \sum_{k=1}^{K} U_{ik} \| x_i^{(k)} - c_k \|^2$$
4. Перегруппировываем объекты для её уменьшения

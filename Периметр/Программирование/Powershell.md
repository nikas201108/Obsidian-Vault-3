### База
Командлет — это встроенные в Powershell команды. Их система именований проста: Глагол-Объект (Delete-Item, Add-Item, Get-Help)

Alias (алиас) — это ассоциации с командлетами, которые хранятся в одноименной папке на компьютере 

1. Ctrl+Home — удаляет всё, начиная с текущей позиции курсора до начала строки
2. Ctrl+End — удаляет с курсора и до конца строки
3. Для того, чтобы скопировать что-то в буфер, выделите это мышью и нажмите Enter.
4. Для того, чтобы вставить строку из буфера — просто нажмите правую кнопку мыши.

-----
### Конвейер (Piping в моей статье про Линукс)	

Когда мы используем какой-то командлет, то он возвращает значение, преобразованное в строку. Конвейер позволяет передать исходное значение в другую функцию. Это выглядит примерно так:
```
«команда 1» | «команда 2»
```

Например, такая команда выведет все процессы и файлы, с которыми они связаны:
```
ps | ls
```

### Get-Help
Алиасы: man, help

Этот командлет позволяет получить справку по командлетам, сценариям, функциях и понятиях Windows shell. Можно написать либо название команды, либо условие (слово, содержащееся в необходимой строке), либо понятие (начинается с `About_`)


| Параметр |     |     | Функция                |     |
| -------- | --: | --- | ---------------------- | --- |
| -Online  |     |     | Поиск в интернете      |     |
| -Example |     |     | Даёт пример применения |     |


Этот командлет может быть заменён такой конструкцией: `<команда> -?`

### Clear-Host
Алиасы: clr, clear

Очищает дисплей, завершает функции и команды даже в процессе. Но не очищает какую-либо информацию, сохраненные результаты

----
### Get-content

Читает файл по определенному пути. 

| Параметр    |     |     | Функция                                   |     |
| ----------- | --: | --- | ----------------------------------------- | --- |
| -Path       |     |     | Путь до файла                             |     |
| -TotalCount |     |     | Число строк, которое должен быть выведено |     |
| -Tail       |     |     | Берёт линию с конца (быстрее индекса)     |     |
|             |     |     |                                           |     |
Кроме того, Get-Content возвращает массив строк, поэтому к нему можно обратиться с помощью указания индекса `[index]` или `[-index]`

ctrl и + — добавление столбца
ctrl и - — удаление столбца

ctrl + маркер заполнения — арифметическая прогрессия с разностью 1

ctrl + end — прыжок в конец таблицы
ctrl + end + home — прыжок в начало 
ctrl + shift + end — выделение таблицы

ctrl + enter с выделенными строками и в строке формул — заполнение формулами

ctrl + enter — заполнение всех выделенных ячеек значением 

(можно создавать ячейка с помощью присвоить имя в формулах)

F4 — изменение типа ссылки

Даты можно вычитать и складывать.

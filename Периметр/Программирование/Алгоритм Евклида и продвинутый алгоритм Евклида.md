## Алгоритм Евклида
Алгоритм Евклида — это алгоритм, предназначенный для нахождения НОД двух чисел. Его принцип работы основан на факте того, что $\textup{НОД}(a,\ b) = \textup{НОД}(a-b,\ b)$

В случае программирования имеет более продвинутую форму: $\textup{НОД}(a\ \% \ b,\ b)$

### Алгоритм
1. На вход подаётся два числа
2. Максимальное число с остатком делиться на минимальное
3. Повторяем, пока не придем к виду $\textup{НОД}(a, 0)$
### Реализация

```python
def gcd(a, b):  
    while b != 0:  
        a, b = b, a % b  
    return a
```

## Продвинутый алгоритм Евклида 

Продвинутый алгоритм предназначен для решения уравнений вида: $$ax+by = \textup{НОД}(a,\ b)$$
### Обоснование
Рассмотри уравнение: $$ax+by = \textup{НОД}(a,\ b)$$
Теперь рассмотрим другое уравнение:$$(b\ \%\ a)x_1+b_1y = \textup{НОД}(b\ \%\ a,\ b)$$
Их можно прировнять, исходя из равенства НОД: $$ax+by=(b\ \%\ a)x_1+b_1y$$
Операцию деления с остатком заменяем на математическое выражение: $b-\lfloor b\div a\rfloor \cdot a$
Тогда, раскрыв скобки, можно выразить: $$\begin{align}&x=y_1-\lfloor b\div a\rfloor\cdot x_1\\&y=x_1\end{align}$$
### Алгоритм 
Создаем рекурсивный алгоритм, который доводит уравнение до вида, когда один член равен равен 0 ($\textup{НОД}(a, 0)$). Начинаем раскручивать обратно и получаем необходимый результат

### Реализация
```python  
def extended_gcd(a, b):  
    if b == 0:  
        return a, 1, 0  
    else:  
        d, x1, y1 = extended_gcd(b, a % b)  
        x = y1  
        y = x1 - (a // b) * y1  
        return d, x, y  
```

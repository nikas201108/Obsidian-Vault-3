 >[!term]- Определение 
 >Множество $R$ элементов $x,\ y,\ z\ldots$ любой природы называется линейным (аффинным) пространством, если выполнены три условия
 >>[!multi-column]
 >>>[!suppoint]- Сумма
 >>>Имеется такое правило, что ставит в соответствие объектам $x$ и $y$ объект $z$
 >>
 >>>[!suppoint]- Произвдедение
 >>>Имеется такое правило, что ставит в соответствие вещественному числу $a$ и объекту $x$ объект $y$
 >

>[!theorem]- Общие теоремы для произвольных линейных пространств 
>>[!suppoint]- В каждом линейном пространстве существует единственный нулевой и единственный противоположный элемент для любого $x$
>>![[Линейные (аффинные) пространства — медиа 2.png]]
>
>>[!suppoint]- В каждом линейной пространстве нулевой элемент равен произведению любого элемента на 0
>>![[Линейные (аффинные) пространства — медиа 3.png]]
>
>>[!suppoint]- Противоположный элемент равен этому элементу, умноженному на -1
>>![[Линейные (аффинные) пространства — медиа 4.png]]

>[!theorem]- Координаты
>Как и в матрице, в пространстве для строк сохраняется понятие линейной зависимости
>Рассмотрим произвольное $R$. Совокупность линейной независимых элементов называется базисом, если: $$\forall x, \ x = e_1x_1+e_2x_2+\ldots+e_nx_n$$
>
>Здесь:
>- $e$ — такая совокупность линейно независимых $n$ строк, что $n+1$ строк линейно независимые
>- $x$ — координаты 
>
>>[!multi-column]
>>>[!suppoint]- Каждый элемент раскладывается по базису единственным способом

>>

>[!info]- Размерность пространства 
>Пространства называется $n$-мерным, если:
>- В нем $n$ линейно независимых элементов 
>- Любые $n+1$ элементы независимы 
>Существует связь между

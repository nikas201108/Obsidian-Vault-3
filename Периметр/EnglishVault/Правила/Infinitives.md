
| Type                                           | Usage                                                          | Example                                                             |
| ---------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------- |
| Simple active<br>(to + V1)                     | Самый стандартный случай. Может использоваться в качестве noun | To go there alone is dangerous<br>The person to contact is Max      |
| Simple passive <br>(to + be + V3)              | Используется в пассивном залоге обыкновенного случае           | To be doubted works like a fuel sometimes<br>I want to be respected |
| Continious <br>(to + be + ing)                 | Используется для передачи продолжительности                    | I am happy to working here<br>He seems to be crying                 |
| Perfect <br>(to + have + V3)                   | Используется для обращения к прошлому                          | He admitted to have robbed the shop<br>I am happy to have done this |
| Perfect passive <br>(to + have + been + V3)    | Используется для обращения к прошлому, но в пассивном залоге   | I am glad to have been selected                                     |
| Perfect continious<br>(to + have + been + ing) | Обращение в прошлое + продолжительность                        | You seem to have been drinking for some hours                       |

## Условие
При подозрении на наличие некоторого заболевания пациента отправляют на ПЦР-тест. Если заболевание действительно есть, то тест подтверждает его в $88\%$ случаев. Если заболевания нет, то тест выявляет отсутствие заболевания в среднем в $92\%$ случаев. Известно, что в среднем тест оказывается положительным у $11\%$ пациентов, направленных на тестирование.
При обследовании некоторого пациента врач направил его на ПЦР-тест, который оказался положительным. Какова вероятность того, что пациент действительно имеет это заболевание?

## Решение
### Решение через проценты
Сначала составим таблицу вероятностей:

|                 | **Тест (✓)** | **Тест (×)** |
| --------------- | ------------ | ------------ |
| **Болезнь (✓)** | $0.88$       | $0.12$       |
| **Болезнь (×)** | $0.08$       | $0.92$       |
|                 | $0.11$       |              |

Пусть $n$ человек пришло в на обследование. Из них больными оказались $k$. Тогда, так как вероятность найти болезнь у болеющего и сделать вероятность неправильный диагноз здоровому  являются несовместными, то их сумма будет равна вероятности положительного теста:
$(n-k)\cdot 0.08 + k \cdot 0.88 = n \cdot 0.11$

Отсюда: $$k = \frac{3}{80}n$$
Составим вероятность того, что пациент имеет заболевание из всех случаев положительного теста:
$$P(A) = \frac{k\cdot0.88}{n\cdot 0.11} = \frac{\cfrac{3}{80}\cdot0.88\cdot n}{0.11\cdot n } = 0.3$$

### Решение через полную вероятность и формула Байеса
Пусть эксперимент заключается в отправке одного случайного пациента на анализ. 

Есть две гипотезы:
- Пациент болен ($H_1$). Пусть $P(H_1) = x$
- Пациент здоров ($H_2$). Тогда $P(H_2) = 1-x$

Из условия следует:
- $P(A) = 0.11$
- $P(A|H_1) = 0.88$
- $P(A|H_2) = 0.08$

Подставляя в формулу полной вероятности получаем: $$\begin{align} &P(A) = P(A|H_1)\cdot P(H_1)+P(A|H_2)\cdot P(H_2)\\&0.88x + 0.08(1-x) = 0.11\\&x =\frac3{80} \end{align}$$
Теперь мы можем найти вероятности гипотезы $H_1$ (пациент болен) при наступлении события $A$ (тест показал положительный результат) по формуле Байеса:$$P(H_1|A) = \frac{P(A|H_1)\cdot P(H_1)}{P(A)} = \frac{0.88 \cdot \cfrac3{80}}{0.11} = 0.3$$

## Комментарий
Одна задача описывает огромный блок из теории вероятности (ЕГЭшной так точно). По сути надо просто понять, какую вероятность мы ищем, и ввести переменные (в некоторых задачах достаточно одной, а где-то две). А дальше просто работать по стандартным законам, но с буквенными значениями 

Это что касалось первого решение, приведенного ещё до моего ознакомления с формулой полной вероятности и формулой Байеса. Второе решение кажется несколько более трудным, поэтому надо сделать несколько оговорок. Оно воспринимается гораздо легче, когда мы смотрим на гипотезы, как те же вероятности в узлах графа (Рисунок временный):

- Формула полной вероятности становится тогда понятной: мы складываем вероятности несовместных событий (гипотезы являются таковыми), предварительно умноженные как независимые на вероятность наступление благоприятствующего нам события
- Теорему Байеса можно рассмотреть в том же ключе: знаменатель представляет собой вероятность наступления события $A$ или, грубо говоря, все случаи, а числитель — вероятность наступления события $A$ при благоприятствующей гипотезы $H$ (то-есть наступление $A$ только через гипотезу)

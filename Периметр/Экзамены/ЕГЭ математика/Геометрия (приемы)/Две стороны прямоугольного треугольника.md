Прямоугольный треугольник можно восстановить по двум данным сторонам

### Два катета
![[Pasted image 20250121204922 1.png]]

1. $$a^2+b^2=AB^2$$
2. $$a^2=AH\cdot AB$$
3. $$b^2=HB\cdot c^2$$
4. $$CH^2=AH\cdot HB$$

### Катет и высота
![[Pasted image 20250121205424 1.png]]
1. $$AH^2=a^2-h^2$$
2. $$h^2=AH\cdot HB$$
3. $$CB^2 = h^2+HB^2$$
4. $$AB^2=a^2+CB^2$$

### Катет и проекция
![[Pasted image 20250121205712 1.png]]

1. $$CH^2 = a^2-c_a^2$$
2. $$CH^2=c_a\cdot HB$$
3.  $$CB^2=HB^2+CH^2$$
### Катет и проекция другого 

![[Pasted image 20250121210046 1.png]]

1. $$a^2=(AB-c_b)\cdot AB$$
2. $$b^2=AB^2-a^2$$
3. $$AH = AB -c_b$$
4. $$CH^2=AH\cdot HB$$

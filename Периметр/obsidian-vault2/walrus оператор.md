Это оператор, который позволяет присваивать значение переменной прямо из действия. Обозначается :=
```python
print(a := 5) # 5
```
Ещё его очень удобно использовать со [[Списковые включения(list comprehension)|списковыми включениями]] и [[Генераторные выражения(genexp)|генераторными выражениями]], ведь не надо вызывать второй раз функцию
```python
#Было 
print([normalization(x / 100) for x  in range(100) if normalization(x / 100) == 1])
#Стало
print([y for x  in range(100) if (y := normalization(x / 100)) == 1])
```

### Python
##### [[Библиотека re]]# Задача: Определение регистрационных знаков транспортных средств

## Условия:
Взято из [ этой статьи](https://habr.com/ru/articles/349860/).
В России применяются регистрационные знаки нескольких видов.  
Общего в них то, что они состоят из цифр и букв. Причём используются только 12 букв кириллицы, имеющие графические аналоги в латинском алфавите — А, В, Е, К, М, Н, О, Р, С, Т, У и Х.
У частных легковых автомобилях номера — это буква, три цифры, две буквы, затем две или три цифры с кодом региона. У такси — две буквы, три цифры, затем две или три цифры с кодом региона. Есть также [и другие виды](https://ru.wikipedia.org/wiki/%D0%A0%D0%B5%D0%B3%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%86%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B5_%D0%B7%D0%BD%D0%B0%D0%BA%D0%B8_%D1%82%D1%80%D0%B0%D0%BD%D1%81%D0%BF%D0%BE%D1%80%D1%82%D0%BD%D1%8B%D1%85_%D1%81%D1%80%D0%B5%D0%B4%D1%81%D1%82%D0%B2_%D0%B2_%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D0%B8#%D0%A2%D0%B8%D0%BF%D1%8B_%D1%80%D0%B5%D0%B3%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%86%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D1%85_%D0%B7%D0%BD%D0%B0%D0%BA%D0%BE%D0%B2_%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D0%B8), но в этой задаче они не понадобятся.
Вам потребуется определить, является ли последовательность букв корректным номером указанных двух типов, и если является, то каким.
| Ввод | Вывод |   
| -------- | -------- |  
| С227НА777 | Private |  
| КУ22777 | Taxi |
| Т22В7477 | Fail |
| М227К19У9 | Fail |
|   " "С227НА777 | Fail |
## Инструменты:
Язык программирования: [[Python]]
Библиотеки: [[Библиотека re|re]], [[Библиотека prettytable|prettytable]]

### Решение:
```python
import re  
from prettytable import PrettyTable  
  
taxi_regex = r"\b[АВЕКМНОРСТУХ]{2}\d{5,6}\b"  
private_regex = r"\b[АВЕКМНОРСТУХ]\d{3}[АВЕКМНОРСТУХ]{2}\d{2,3}\b"  
cars = []  
  
while True:  
    string = input()  
    if re.match(taxi_regex, string):  
        cars.append((string, 'Taxi'))  
    elif re.match(private_regex, string):  
        cars.append((string, 'Private'))  
    elif string == "":  
        break  
    else:  
        cars.append((string, 'Fail'))  
print(cars)  
output_table = PrettyTable()  
output_table.field_names = ["Number", "Vehicle registration ID", "Output"] 

for number, (car, output) in enumerate(cars):  
    output_table.add_row([number+1, car, output])  
  
print(output_table)
```

### Рефлексия:
В данном случае для реализации лучше всего подходили [[Regular expression — регулярные выражения|регулярные выражения]], так как они дали  работать с фиксированными шаблонами(номерные знаки). Также для таблички использовалась prettytable. Можно было объединить циклы, но вариант с enumerate оказался интереснее.

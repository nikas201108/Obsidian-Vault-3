Функции [[Функция list.sort|list.sort]] и [[Функция sorted|sorted]] кажутся похожими, но имеют отличия:
- list.sort работает только со списками, а sorted принимает любой итерируемый объект
- list.sort возращает None, непосредственно изменяя исходный список, а sorted всегда возращает список.

Функции принимают два необязательных аргумента:
- reverse. По умолчанию False
- key. Это ключ сортировки. Может принимать любую функцию. Если надо отсортировать по длине, то используем len, если буквы должны быть маленькими — lower

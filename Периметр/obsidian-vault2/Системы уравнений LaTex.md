Систему уравнений можно получить с помощью этой конструкции:
```latex
	\[\left\{
	\begin{aligned}
		&x + y = 10 \\
		&x^2 + 3x - 3 = 2
	\end{aligned}\right.
	\]
```
Здесь:
- Все выражение обернуто в формулу
- \\[[\left]] и \\[[\right]] позволяют расширить скобку, где \\right — фантомная
- [[Знак &]] отвечает за центрирование

Чтобы описать кусочно-заданную функцию мы используем класс [[Класс cases|cases]], обернутый в класс [[Класс equation|equation]]
```latex
	\begin{equation}
		f(x) = \begin{cases}
			1, \text{если } x \ge 0,5\\
			0, \text{если } x < 0,5
		\end{cases} 
	\end{equation} 
```

Если хотим писать ручками, то используем eqarray.

Чтобы инициализировать документ в [[LaTex]] существует алгоритм действий, состоящий из трёх команд:
1) Создание [[documentclass]]. Это первая необходимая для LaTex команда, которая говорит тип документа, ведь разные типы содержат разные команды и оформления. Принимает в квадратных скобках опции, а в [[Фигурная скобка {}|фигурных]] класс
```latex
\documentclass[опции]{тип}
```
3) Начало документ с [[begin]]
4) Конец документа с [[end]]

Основные классы документов:

| Класс | Назначение | 
| ---------- | --------- | 
| article | статьи, документации | 
| report | используется для диссертаций, так как поддерживает главы, колонтитулы| 
| book | книги, главы, колонтитулы и поля |
| beamer | презентации |
| letter | американское оформление писем |

Параметры:

| Параметры | Назначение | 
| ---------- | --------- | 
| 10pt/11pt/12pt | меняет размер шрифта | 
| 1**| меняет размер листа| 
| draft | выделяет проблемные моменты |
| fleqn | включает центрирование формул по левому краю по умолчанию |
| leqno |  размещает номера формул слева от формулы, а не справа |
| titlepage/notitlepage |  создает и не создает титульную страницу |
| twoside/oneside | чётные и нечётные страницы различаются полями, потому что будет прошивка в виде книги|

	1** - _a4paper_, _letterpaper_, _a5paper_, _b5paper_, _executivepaper_, _legalpaper_

Пространство между documentclass и begin — [[Преамбула|преамбула]](служебные команды).

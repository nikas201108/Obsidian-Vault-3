array в [[Python]] полезен, когда нам нужен очень большой список, так как он хранит информацию в байтах и имеет специальные методы. Буква при объявлении массива задает тип в языке C. 
array импортируется из [[Библиотека array|библиотеки array]]

```python
floats = array('d', (random() for i in range(10**7)))
```

| Значение | Символ |   
| -------- | -------- |  
| b | \[-127, 128] |
| h | \[-32.768, 32.767] |
| i | \[-2.147.483.648, 2.147.483.647] |
| q | много |
| f | float |
| double | big float |

array.to_file — эффективно записывает числа
array.from_file — читает

Эти методы работают в 7 и 60 раз быстрее чем обычные.

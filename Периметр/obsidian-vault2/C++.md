
# Hello world
```cpp
     #include <iostream>
     using namespace std;
     int main()
     {
        cout<<"Hello, world!"<<endl;
        return 0;
     }
```

1. `include <iostream>` отвечает за подключение стандартной библиотеки ввода-вывода
2. `using namespace std` показывает, что мы используем все пространство имён и все функции стандартной библиотеки C++
3. Функция `main` — основная функция в программе
4. При помощи оператора `<<` помещаем в `cout` строку и символ перехода каретки (`endl`)

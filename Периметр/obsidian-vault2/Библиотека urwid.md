[[Виджет Text]] — это потоковый текстовый виджет, который занимает столько места, сколько возможно. Может быть установлено значение через callable или set_text. Для текста можно выбрать align. Чтобы задать оформление используем кортеж, который содержит стиль и текст

[[Виджет Filler]] — это виджет, который заполняет строки невидимыми символами. Принимает виджет, который должен быть заполнен, 'top', 'middle', 'bottom' и 'relative'(в процентах), top = строки, bottom = строки.

[[Виджет MainLoop]] отвечает за отображение и input. unhandled_input передает нажатие клавиши функции, если она не передана другим виджетам

В плане палитры она представляет из себя кортеж, содержащий:
1. имя атрибута 
2. foreground цвет(16-color mode)
3. background цвет(16-color mode)
4. Настройки для моно режима
5. foredround цвет(256-color mode)
6. background цвет(256-color mode)

AttrMap позволяет обернуть одни атрибуты в другие

[[Виджет Divider]] — это виджет для создания пустых линий, заполненных цветом.

Некоторые свойства определяются с помощью кортежа (виджет, настройка)

[[Виджет SolidFIll]] — заполняет все пространство одним символом('', но можно задать  )

.original_widget отвечает за оригинальный виджет.

Overlay отображает один виджет поверх другого. Он принимает сначала верхний блок, потом нижний. Дальше идет выравнивание('left, center, right, relative\[0=лево, 100=право]') по горизонтали align и по вертикали valign.  width отвечает за ширину(pack если фиксирована и relative в процентах). height тоже самое. min_height и min_width в столбцах.

boxadapter, чтобы фиксить роусы.


$\begin{multline}\text{\textit{ Каково бы ни было значение n, сумма }} 1+2+3+\ldots+n \\ \text{\textit{ первых n натуральных чисел равна }} \frac{n(n+1)}{2} \end{multline}$ 
Докажем это утверждение:
Во-первых, допустим, что: $$S_r = 1 + 2 + 3 + \ldots + r = \dfrac{r(r+1)}{2}$$
Тогда, добавим $(r + 1)$:$$1+2+3+\ldots+r +(r+1) = \frac{r(r+1)}{2}+(r+1)$$
$$\frac{r(r+1)}{2}+(r+1) = \frac{r(r+1)+2(r+1)}{2}$$
$$S_{r+1} = \frac{r(r+1)+2(r+1)}{2} = \frac{(r+1)(r+2)}{2}$$
$$1+2+3+\ldots+r +(r+1) = \frac{(r+1)(r+2)}{2}$$
Утверждение справедливо, так как при подстановке в исходную формулу $r+1$ тот-же результат. Во-вторых, докажем, что первое утверждение справедливо: $$S_1 = 0+1= \frac{1\times(1+1)}{2}=1$$
Значит, утверждение доказано для бесконечного ряда чисел по методу математической индукции.

Теперь мы можем вывести общую арифметическую прогрессию:
$$\begin{multline}P_n= a+(a+d) + a+(a+2d)+\ldots+ (a+dn)= \\= an+S_{n-1}d=a(n+1)+S_nd=\\=a(n+1)+\frac{n(n+1)d}{2}=\\=\frac{2a(n+1)+nd(n+1)}{2}= \frac{(n+1)(2a+nd)}{2}\end{multline}$$

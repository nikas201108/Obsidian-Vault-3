Суть бинарного поиска в массиве заключается в том, что  мы находим срединное значение `m` и сравниваем с целевым значением `k`. Отталкиваясь от этого сравнения,  передвигаем границу поиска
```python
array = sorted(list(map(lambda x: int(x), input().split())))
l = 0
r = len(array)
k = int(input())

while l < r:
    m = (l + r) // 2
    if array[m] <  k:
        l = m + 1
    else:
        r = m

if array[r] == k:
    print(r)
else:
    print(-1)
 
```

С помощью этого метода можно также искать значения монотонно возрастающих функций, как в этой задаче поиска квадратного корня
```python
r = int(input())
l = 1

while abs(l-r) > 0.005:
    m=(l+r)//2
    if (m**3 < r):
        l = m + 1
    else:
        r = m
print(r)

```

Генераторные выражения — это конструкции в[[Python]], которые похожи на [[Списковые включения(list comprehension)|списковые включения]], но их вывод не представляет из себя список, а другие типы данных.

```python
print(tuple(x+1 for x in range(3))) # (1, 2, 3)
```

Генераторные выражения:
1.     Генерируют последовательности отличные от списков
2.     Вывод последовательности, не хранящейся целиком в памяти, что позволяет ускорять программу в некоторых случаях. Например: 
```python
colors = ['black', 'white']
sizes = ['S', 'M', 'L']
for tshirt in ('%s %s' % (c, s) for c in colors for s in sizes):
print(tshirt)
```

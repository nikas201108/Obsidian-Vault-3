Кортежи имеют две функции:        
	1.     Неизменяемые списки
	2.     Записи с неименоваными полями

Во втором случае часто очень важен порядок элементов и их количество.
```python
traveler_ids = \[('USA', '31195855'), ('BRA', 'CE342567'), ('ESP', 'XDA205856')\]
```
Здесь при нарушении порядка будет нарушена логика.

Распаковка кортежа происходит с помощью конструкции for x in:
```python
for country, _ in traveler_ids:
	print(country) # USAm, BRA, ESP
```
Здесь _ — фиктивная переменная

Также мы можем использовать конструкцию % ().
```python
for passport in sorted(traveler_ids):
	print('%s/%s' % passport) 
#BRA/CE342567
#ESP/XDA205856
#USA/31195855
```

Распаковать кортеж ещё можно с помощью:
1. Параллельное присваевание
```python
a, b = tuple
```
2. Распаковка звездочкой
```python
function(*tuple)
```

Чтобы распаковать кортеж в кортеже надо использовать for x, (y, z) in tuple, где (y, z) — вложенный кортеж.

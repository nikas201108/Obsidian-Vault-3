Пусть массив называется `a`   и состоит из `n` элементов, а искомое `k`. Тогда решение будет примерно таким и оно будет искать последнее вхождение:

```python
import random
k = int(input())
a = [random.randint(0, 100) for x in range(100)]
j = 0
for x in range(len(a)):
    if a[x] == k:
        j = x
```
Сложность $O(N)$

Для первого вхождения можно рассмотреть барьерный метод:
```python
import random
k = int(input())
a = [random.randint(0, 100) for x in range(100)]
a.append(k)
for x in range(len(a)):
    if a[x] == k:
        break
print(x)
```

Нахождения минимума и максимума (последнее вхождение):
```python
import random
imin = 0
imax = 0
a = [random.randint(0, 100) for x in range(100)]
for x in range(len(a)):
    if a[x] < a[imin]:
        imin = x
    if a[x] > a[imax]:
        imax = x
print(imin)
print(imax)
```
Здесь количество сравнений $2\times N$ 

Другая реализация, основанная на разбиении по парам:
```python
import random
imin = 0
imax = 0
a = [random.randint(0, 100) for x in range(100)]
lmin = []
lmax = []
for x in range(0, len(a), 2):
    if a[x] > a[x+1]:
        lmax.append(a[x])
        lmin.append(a[x+1])
    else:
        lmax.append(a[x+1])
        lmin.append(a[x])

for x in range(len(lmin)):
    if lmin[x] < lmin[imin]:
        imin = x

for x in range(len(lmax)):
    if lmax[x] > lmax[imax]:
        imax = x
```
Здесь количество сравнений $3\times N/2$

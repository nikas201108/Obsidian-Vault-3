## [[Python]]
\__repr\__  — это [[Магические методы(Dunder-методы)|дандер-метод]], который выводит класс через print(), но в отличие от [[Дандер-метод __str__|дандер-метода __str__]], делает это максимально подробно, максимально определенно так как несет скорее технический характер.  

> [!tip] 
> > В чем идея: __str__ выводит значение в красивом, удобном, читабельном виде, а __repr__ является максимально определенным, где мы должны видеть все типы объектов для возможного восстановления объекта(чтобы понимать его внутреннюю природу.. Поэтому если в __str__ допустимо не видеть типы аргументов, то в __repr__ — нет(грубо говоря надо писать все, что мы знаем об экземпляре).
> 

```python
class Vector:  
    def __init__(self, x, y):  
        self.x = x  
        self.y = y  
  
    def __repr__(self):  
        return 'Vector(%r, %r)' % (self.x, self.y)  
  
a = Vector(3, 5) 
print(a)# Vector(3, 5)
```

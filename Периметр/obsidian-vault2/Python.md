Python — это удобный интерпритируемый язык программирования, который является крайне многофункциональным из-за большого количества встроенных и пользовательских библиотек.
Некоторые из них:
+ [[Библиотека re|re]] — библиотека, реализующая [[Regular expression — регулярные выражения|регулярные выражения]]
+ [[Библиотека NumPy|NumPy]]/[[Библиотека pandas|pandas]] — библиотека для работы с большими объемами информации(различные матрицы и таблицы)
+ [[Библиотека matplotlib|matplotlib]] — библиотека для работы с графиками

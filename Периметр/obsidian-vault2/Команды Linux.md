## [[Linux]]

Команды на Linux и Mac похожи, потому что они наследуется от Unix. Windows — нет.  
Ричард Столлман был лидером движения «Free software». Он начал проект GNU, цель которого заключалось в разработке альтернативы Unix, но с open-source кодом.  
В это время Линус Торваладс разрабатывал свой kernel под названием Linux  
И в итоге у них подучился Unix подобная система.

~ значит /home/user/(называется home directory)  
/ значит root directory

{characters} — перебирает все возможные варианты в скобочках
echo {a, b, c}.py становится a.py, b.py и c.py

-v как правило показывает итоги операции

\> позволяет перевести вывод не в терминал, а в другое место(заменяет содержимое)
\>> позволяет перевести вывод не в терминал, а в другое место(добавляет в последнюю строчку)

Piping. Использование | передает команде справа вывод команды слева

ctrl+c — уничтожение текущей команды
ctrl+z — приостановка. [[Команда jobs]] показывает текущие команды. [[Команда fg]] восстанавливает процесс(продолжает работу). [[Команда bg]] продолжит, но не показывает


[[Команда cat]] — вывод текста файла. Принимает один или несколько файлов(конкатенация). -n выводит и номер строки.
[[Команда less]] — открывает UI для просмотра файла. 
[[Команда echo]] — возвращает переданный аргумент. Чаще всего используется для записи в файл
[[Команда head]] — вывод первых нескольких строк файла(-n позволяет указать кол-во строк)
[[Команда tail]] — вывод последних строк файла(-n позволяет указать кол-во строк)(-f позволяет обновлять файл динамично)
[[Команда man]] — просмотр документации 
[[Команда sudo]] — команда, которая позволяет запускать программы или команды с привилегиями другого пользователя. Root пользователь может делать всё, но его нельзя выбрать.
[[Команда shoutdown]] — команда, которая выключает или перезагружает компьютер. Имеет опции -r(reboot) и -h(время перед выключением или перезагрузки). Может принимать строку в качеству аргумента
[[Команда which]] — команда, которая ищет исполняемый файл. Принимает имя файла и путь.
[[Команда echo]] — выводит строку
[[Команда pwd]] — выводит текущую директорию 
[[Команда cd]] — меняет директорию(родительская директория — .., а прошлая минус)
[[Команда tree]] — команда, которая показывает дерево. -a — скрытые файлы, -f — префикс полного пути, -d — только подкаталоги, L — максимальная глубина
[[Команда whoami]] — команда, которая выводит имя пользователя  
[[Команда man]] — команда, которая выводит документацию программы  
[[Команда help]] — команда, которая является аналогом man  
[[Команда clear]] — команда, которая очищает терминал  
[[Команда ls]] — команда, которая выводит список файлов в директории. Может принимать -l(выводит полную информацию); -a(выводит скрытые файлы)
[[Команда mkdir]] — создает папку. -p создает автоматически родительские папки пути
[[Команда rmdir]] — удаляет папки(пустые)
[[Команда rm]] — удаляет файлы и директории(использовать -r) 
[[Команда touch]] — создает файл. Если существует, то открывает в режиме редактирования
[[Команда open(xdg-open)]]  — открывает файл
[[Команда mv]] — позволяет переместить файл(также можно переименовать)
[[Команда cp]] — копирует файл или папку(-r)
[[Команда date]] — выводит дату
[[Команда wc]] — возвращает кол-во строк, биты, символы и т.п. о файле. Через параметр можно обратиться к конкретному значению.
[[Команда sort]] — сортирует файл(смотреть параметры, чтобы установить различные сортировки.) Флаг -u сортирует только уникальные объекты. 
[[Команда unique]] — в стандартном поведение оставляет только один экземпляр повторяющейся строки, а остальные удаляет. -d — выводит экземпляры, повторяющихся строк. -u, которые встречаются только один раз. -c считает вхождения
[[Команда diff]] — показывает разницу между файлами. -u показывает информацию в немножко другом виде.
[[Команда find]] принимает путь, опцию для нахождения и аргумент.  -name — ищет по имени. -d — только директории. -i не различает строчные и заглавные буквы. -or, -not. -size  +100k -size -1M — ищет по размеру  от 100 килобайтов до 1 мегабайта. -mtime — по времени(похоже на размер с ограничением). -exec — выполнить операцию над всеми найденными файлами. -h для команды du
[[Команда grep]] позволяет производить поиск внутри файла. Принимает то, что мы ищем и имя файла. -n показывает линии. -nС сколько линий должно идти после и перед совпадением. -r ищет во всей директории. Можно снабдить регулярными выражениями.
[[Команда du]] — считает сколько места занимает файл или директория. -m — мегабайты, -g — гигабайты, -h — human readable size.
[[Команда df]] — более подробная версия du с доп. параметрами диска.
[[Команда history]] — выводит историю ввода и вывода команд. Записью !номер_команды можно повторить команду.
[[Команда ps]] — используется, чтобы получить информацию о процессе. Чаще всего используется с ax, чтобы получить все процессы.
[[Команда top]] — открывает подробное окно с процессами(объединенными).
[[Команда kill]] — принимает id процесса и уничтожает его. -l — показывает все возможности. -9 — alt+f4, -15  — спокойное отключение.
[[Команда killall]] — уничтожает не отдельный процесс, а программу.
[[Команда sleep]] — приостанавливает работу программы.
[[Команда gzip]] — cжимает отдельный файл(не сохраняет исходный). -k сохраняет исходный.
[[Команда gunzip]] — открывает архив.
[[Команда tar]] — создает архив. Основный синтаксис tar -cf name file1 file2: -c(create) и -f(filename). -xf раскрывает файл(возможен -C чтобы переместить в другую директорию). -tf позволяет посмотреть содержимое архива. После этого можно еще обработать через gzip. -z совмещает с gzip
[[Команда nano]] — открывает текстовый редактор nano.
[[Команда alias]] — позволяет создать макрос. Записывается как: alias \[имя макроса]='\[команда]'(или ""). Но  макрос распространяется на конкретное окно. Чтобы оно сохранялось надо вписать alias в файл .bashrc. '\$PWD' — строка, "\$" — переменная среды.
[[Команда xargs]] — разбивает content на аргументы.
[[Команда ln]] — создает hard и soft ссылки. Hard ссылка ссылается на один и тот же объект в памяти, поэтому даже на удаление оригинального файла пофиг. Soft ссылка делается через -s и уже полностью зависит от оригинального файла.
[[Команда who]] — показывает, кто сейчас залогинин на компьютере
[[Команда su]] — меняет пользователя.
[[Команда passwd]] — позволяет сменять пароль свой или чужой
[[Команда chown]] — передает владение директорией другому пользователю.

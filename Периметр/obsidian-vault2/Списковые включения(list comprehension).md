Списковые включения в [[Python]] — это конструкции вида: \[x for x in range(20)], которые выдают в итоге список. 
Может быть использован для декартова умножения.

```python
print([x+1 for x in range(3)]) # 1, 2, 3
```

Иногда используется в связке с [[walrus оператор|walrus оператором]]

Не следует путать с [[Генераторные выражения(genexp)|генераторными выражениями(genexp)]].

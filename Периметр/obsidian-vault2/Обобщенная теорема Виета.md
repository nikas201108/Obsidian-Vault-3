Если $x_1, x_2, \ldots, x_n$ — корни многочлена $n$-ой степени
$a(x) = a_n\times x^n + a_n-1\times x^{n-1} + \ldots + a_1\times x + a_0$,
то справедливы равенства:
$x_1x_2\ldots x_{n-1} + x_1x_2\ldots x_{n-2}x_n + \dots + x_2x_3\ldots x_n = (-1)^{n-1}\dfrac{a_1}{a_n}$ $x_1x_2\ldots x_{n-1}x_n = (-1)^n\dfrac{a_0}{a_n}$

 Соответственно для $ax^2 + bx + c = 0$:
 $x_1x_2 = \dfrac{c}a$
$x_1 + x_2 = -\dfrac{b}{a}$

## Метод выбора
Основная идея заключается в том, что мы просто идём по массиву, находим меньший элемент и ставим его на первую позицию, постепенно сдвигаясь в конец массива
![[Pasted image 20240625091117.png]]

```python
array = list(map(int, input().split()))  
for i in range(len(array) - 1):  
    imin = i  
    for j in range(i, len(array)):  
        if array[j] < array[imin]:  
            imin = j  
    temp = array[i]  
    array[i] = array[imin]  
    array[imin] = temp  
  
print(array)
```
Сложность $O(N^2)$

## Метод вставки
Вставим элемент `k` в отсортированный по возрастанию массив. Для этого найдем такой индекс, что `array[k-1] < array[k]`, но `array[k] < array[k+1]` 

```python
array = list(map(int, input().split()))  
k = int(input())  
i = 0  
temp = 0  
try:  
    while k > array[i]:  
        i += 1  
    array[i + 1:len(array)] = array[i:len(array)]  
    array[i] = k  
except:  
    array.append(k)  
print(array)
```
Сложность от $O(N^2)$ (сдвигать всё) до $O(N)$. Может пригодиться, когда мы добавляем несколько элементов в большой массив, чтобы не сортировать его заново

## Метод простого обмена или пузырьковая сортировка
Суть состоит в том, что мы поочередно просматриваем пары чисел и сравниваем их — большое число в паре окажется правее, а меньшее — левее. Причём по результатам одного такого прогона по массиву мы сразу же можем найти большое число
![[Pasted image 20240625100346.png]]
Перед написанием кода надо сказать про два утверждения-оптимизатора:
- Если массив состоит из условных $N$ чисел, то из определения нам необязательно каждый раз проходить его снова, а пройти только $N-i$, так как с конца будут оставаться только уже отсортированные значения
![[Pasted image 20240625100639.png]]
- После каждого прогна стоит проверять, изменился ли список. А то он может оказаться отсортированным уже на первом сравнении (3, 1, 2)

```python
array = list(map(int, input().split()))  
i = 1  
temp = []  
while i <= len(array):  
    for j in range(len(array) - i):  
        if array[j+1] < array[j]:  
            array[j], array[j+1] = array[j+1], array[j]  
    i += 1  
    if temp == array:  
        break  
    temp = array.copy()  
  
print(array)
```

## Сортировка с убывающими смещениями
По сути это расширенный вариант пузырьковой сортировки, но здесь мы 
предварительно делаем проход с постепенно уменьшающимся значением `d` (в примере уменьшается в два раза) с тем же стандартным принципом перестаовки
```python
array = list(map(int, input().split()))  
i = 1  
temp = []

d = len(array) // 2
while d > 1:
    for j in range(0, len(array) - d):
        if array[j+d] < array[j]:  
            array[j], array[j+d] = array[j+d], array[j]
    d //= 2

while i <= len(array):  
    for j in range(len(array) - i):  
        if array[j+1] < array[j]:  
            array[j], array[j+1] = array[j+1], array[j]  
    i += 1  
    if temp == array:  
        break  
    temp = array.copy()  
  
print(array)

```

## Быстрая сортировка
Выбираем любой элемент массива (в нижеприведенном случае последний) и сравниваем с ним другие элементы массива, распределяя их в соответствующие массивы. Все повторяем рекурсивно 
```python
array = list(map(int, input().split()))  
  
  
def divide(arr):  
    if len(arr) <= 1:  
        return arr  
    l_arr = []  
    g_arr = []  
    eq_arr = []  
    pivot = arr[-1]  
    for x in range(len(arr)):  
        if arr[x] < pivot:  
            l_arr.append(arr[x])  
        if arr[x] == pivot:  
            eq_arr.append(arr[x])  
        else:  
            g_arr.append(arr[x])  
    return divide(l_arr) + eq_arr + divide(g_arr)  
  
  
print(divide(array))
```
Это одна из самых быстрых сортировок в беспорядочном наборе данных, но её эффективность может зависеть от взятого `pivot`'а. $O(\log n)$, $O(n)$, $O(n^2)$

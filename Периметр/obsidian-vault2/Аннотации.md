Аннотации — это инструмент, помогающий читающему код понять какие типы данных принимаются в определенную функцию, какой тип данных возращается и т.п. В целом языком они почти не учитываются и не несут какую-то практическую пользу, а нужны конкретно для удобства пользователей.

### [[Python]]
В Python простые аннотации уже встроенны в язык, а более сложные предоставляет встроенная библиотека typing.
Из простых можно выделить:
- Аннотация переменных.
```python
a: int
b: int = 1
```
- Аннотация функций(где аргументы оформляются, как переменные, а то что выводет функция через ->). Если фунцкия ничего не возращает, то тип вывода — None. NoReturn — функция ничего и никогда не возращает. Если в функции есть [[yield]], то можно использовать [[Встроенный тип Iterable(typing)]].
```python
def hello_world(a: str, b: int) -> list:
	...
```
- Аннотация классов(здесь желательно аннотировать и в теле класса, и в __init__()
```python
class CartesianCoordinateSystem:
	x: float
	y: float
	def __init__(self, x: float, y: float) -> None:
		...
```

Если у вас есть тип, который ещё не создан на время выполнения кода, то вы можете использовать эту конструкцию.
```python
class Vector3:
	a: 'Vector2'

	def __init__(self, a: 'Vector2'):
		pass

class Vector2:
	...
```
Однако, [[Библиотека typing|библиотека typing]] предлагает дополнительные возможности.

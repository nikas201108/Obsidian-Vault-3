Образ функции — это множество всех значений, которые даёт функция.  
Вычисление заданной функции $f$ для каждого элемента определенного подмножества $A$ области определения функции даёт множество, называемое «образом $A$ для функции $f$». 

$f: X \rightarrow Y$. Функция из множества X в множество Y:
1. Если $x \in X$, то образ $x$ для функции $f$ — это $f(x)$ или значение функции для аргумента x
2. Образ $A \subseteq X$ для функции $f$, обозначаемый $f[A]$, является подмножеством множества $Y$: $$f[A] = \{f(x)\text{ | } x \in A\}$$
3. Образ функции — это образ [[Область определения функции(математика)|области определения функции]], соответственно [[Область значений функции(математика)|области значений функции]]. 

[[Обратный образ]](обозначается $f^{-1}[\dots]$, $f^{-1}(\dots)$ и $f^{-}(\dots)$), когда $f: X \rightarrow Y$, множества $B \subseteq Y$ для функции $f$ — это подмножество:$$f^{-1}[B] = \{x \in X \text{ | } f(x) \in B\}$$

### [[Python]]
В Python работает совместно с [[Дандер-метод __enter__]]. Нужен для коректной работы выражения [[менеджеры контекста with ... as|with ... as]]: он отвечает за операции, которые будут происходить после выхода из конструкции.
```python
def __exit__(self, exc_type, exc_value, traceback):...
```
Здесь:
- self — экземпляр класса
- exc_type — тип зафиксированного исключения, либо None.
- exc_value — объект зафиксированного исключения, либо None
- traceback — [[трассировка стека]] для исключения, либо None

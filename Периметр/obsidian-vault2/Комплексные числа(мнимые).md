Комплексные числа($\large \mathbb{C}$) — это множество чисел, которые имеют вид $z = a+bi$,  где:
- $a \text{ и } b \in \mathbb{R}$
- $i$ — мнимая единица
- Число $a$ — действительная часть числа $z$ или $Re \ z$
- Число $b$ — мнимая часть числа $z$ или $Im \ z$
Основным равенством можно считать для этого множества можно считать $$i^2 = -1$$

## Геометрическая интерпретация 
Комплексные числа отображаются на комплексной плоскости.![[Комплексные числа — медиа 1.png.png]]

## Алгебраическая форма комплексного числа
Смотреть выше $z = a + bi$

- Сложение $$\begin{aligned} z_1=1+3i \\ z_2 = 4-5i \\ z1+z_2 = 1+3i + 4 - 5i = 5 - 2i \end{aligned}$$
Свойства:
1. [[Коммутативность]]
$$z_1 + z_2 = z_2 + z_1$$
2. [[Ассоциативность]]
$$z_1+(z_2+z_2)=(z_1+z_2)+z_3$$
- Вычитание $$\begin{aligned}z_1 &= -2+i \\ z_2 &= \sqrt 3 + 5i \\ z_1-z_2 &=-2+i-\sqrt 3 -5i = -(2+\sqrt 3) - 4i \\ z_2 - z_1 &= \sqrt 3 + 5i +2 -i = \sqrt 3 + 2 +4i\end{aligned}$$
- Умножение
$$\begin{aligned}z_1 = 1-i \\ z_2 = 3+ 6i \\z_1 \times z_2 = (1-i)(3+6i) = 3 +6i-3i+6 = 9+3i\end{aligned}$$
Также есть специальная формула $$z = (a_1a_2-b_1b_2)+(a_1b_2+a_2b_1)i$$1. [[Коммутативность]]
$$z_1\times z_2 = z_2 \times z_1$$
2. [[Ассоциативность]]
$$z_1\times(z_2\times z_3) = (z_1\times z_2)\times z_3$$
- Деление производится с помощью сопряженного комплексного числа $$\begin{aligned}z_1 = 13 + i \\z_2 = 7-6i\\ \frac{z_1}{z_2} = \frac{13+i}{7-6i}=\frac{(13+i)(7+6i)}{49+36}=\frac{91+78i+7i-6}{85}=\\=\frac{85+85i}{85}=1+i\end{aligned}$$

## Задача на запись числа $z$ в виде алгебраической формы.
Пусть $z = \dfrac{1}{\sqrt 3 + i}$. Тогда $$z= \frac{1}{\sqrt 3 + i} = \frac{\sqrt 3 - i}{3 + 1} = \frac{\sqrt 3 - i}{4} = \frac{\sqrt 3}{4} - \frac{1}{4}i$$  

## Тригонометрическая форма комплексного числа
$$\forall z \in \mathbb{C}\text{, кроме } z=0\colon z = |z| \times (\cos \phi + i \times \sin \phi)$$
![[Комплексные числа — медиа 2.png.png]]

Модуль комплексного числа $z$ — это расстояние от начала координат до точки комплексной плоскости или длина радиус-вектора. Он обозначается $|z|$ или $r$.
$$|z| = \sqrt{a^2 + b^2}$$
Аргументом комплексного числа $z$ называют угол $\phi$ между положительной  полуосью действительной оси $Re \ z$  и радиус-вектором, проведенным из начала координат. Аргумент не определен для $z = 0$. Аргумент комплексного числа обозначают $\phi$ или $\arg z$. 

$\arg z$  в правой полуплоскости находится по формулам:
1) если $a > 0$$: $$\arg z = \arctan \frac{b}{a}$$
2) Если $a < 0$ и  $b > 0$: $$\arg z = \pi + \arctan \frac{b}{a} $$
3) Если $a<0$  и $b < 0$: $$\arg z = -\pi + \arctan \frac{b}{a}$$

Углы правой полуоси $0$ и $\dfrac{\pi}{2}$. 
Углы левой части $\pi$ и $\dfrac{3\pi}{2}=\dfrac{-\pi}{2}$   более официально. 
##### Упрощать запись нельзя! 

Умножение комплексных чисел в тригонометрической форме происходит по этой формуле: $$z_1\times z_2=|z_1|\times|z_2|\times (cos(\phi_1+\phi_2)+i\sin(\phi_1+\phi_2))$$

## Показательная форма
$$z = |z|\times e^{i\phi}$$
Умножение для показательной формы происходит так:
$$z_1\times z_2 = |z_1|\times|z_2|\times e^{i(\phi_1+\phi_2)}$$
## Возведение комплексных чисел в степень
1) При возведении во вторую степень можно воспользоваться слегка модифицированными формулами сокращенного умножения $$(a+bi)^2 =a^2+2abi-b^2$$$$(a-bi)^2=a^2-2abi-b^2$$
$$(a+bi)^3=a^3+3a^2bi-3ab^2-b^3i$$
$$(a-bi)^3=a^3-3a^2bi-3ab^2+b^3i$$ 
2) Формула Муавра $$z^n=|z|^n\times(\cos(n\phi)+i\sin(n\phi))$$
Пример:$$\begin{multline}z^{20}=(2\sqrt 3)^{20}\times \biggl(\cos\Bigl(20\times \frac{\pi}{6}\Bigr)+i\sin\Bigl(20\times\frac{\pi}{6}\Bigr)\biggr) = \\=(2\sqrt 3)^{20}\times \biggl(\cos\frac{10\pi}{3}+i\sin\frac{10\pi}{3}\biggr)
\end{multline}$$
Этот пример решён, но можно несколько упростить радианы. Один оборот равен $2\pi$ радиан $\Rightarrow$ $\dfrac{10\pi}{3} = 3\dfrac{1}{3}\pi=\dfrac{4\pi}{3}$
Значит $$z^{20} = (2\sqrt 3)^{20} \times \biggl(\cos \frac{4\pi}{3} + i\sin \frac{4\pi}{3}\biggr)$$
Но мы можем убавить ещё один оборот, получив стандартный вид $$z^{20}=(2\sqrt 3)^{20} \times 
\Biggl(\cos \left(\frac{-2\pi}{3}\right)+i\sin\left(\frac{-2\pi}{3}\right)\Biggr)$$
5) Возведение в степень нечетной единицы:
	1) Если степень чётная, то делаем так: $$i^n = (-1)^{2^{\frac{n}{2}}}$$
	2) В ином случае: $$i^n=i^{n-1}\times i^{2^\frac{n-1}{2}}$$
	3) Коэффициент: $$(-i)^{21}=(-1)^{21}\times(i)^{21}=\ldots$$

2)  Универсальная формула $$z = \sqrt[n]{w}$$
$$z_k=\sqrt[n]{|w|}\times\left(\cos\left(\frac{\phi+2\pi k}{n}\right)+i\sin\left(\frac{\phi+2\pi k}{n}\right)\right)$$
$k =\{1, \ 2,\  ..., \ n-1\}$

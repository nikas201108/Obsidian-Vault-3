random.sample(population, k, counts) — это функция библиотеки [[Библиотека random|random]], которая первым аргументом принимает последовательность или [[set]](До Python 3.9), а вторым — количество выбираемых из последовательности элементов(должно быть меньше чем размер последовательности). Counts - что-то наподобии весов. 
```python
import random  
  
t = [1, 2, 3, 4, 5]  
print(random.sample(t, 3))  # Вывод: [5, 3, 4]

d = [1, 2, 3]  
print(random.sample(d, 3, counts=[1, 2, 3]))  # Вывод: [3, 2, 3]
```

counts превращает список в d = [1, 2, 2, 3, 3, 3]


$G_n = a + aq + aq^2 + \ldots + aq^n = \dfrac{a(1-q^{n+1})}{1-q}$
Докажем эту формулу для любого $n$. Во-первых, рассмотрим случай $G_1$. $$G_1 = a(1 + q) = \frac{a(1-q^2)}{1-q}=\frac{a(1+q)(1-q)}{1-q}=a(1+q)$$
Теперь установим правило:
$$\begin{multline}G_{r+1} = (a + aq + aq^2 + \ldots + aq^r)+aq^{r+1} =\\ =\dfrac{a(1-q^{r+1})}{1-q}+ aq^{r+1}=\\=\dfrac{a-aq^{r+1}+ aq^{r+1}-aq^{r+2}}{1-q}=\frac{a-aq^{r+2}}{1-q} =\\=\frac{a(1-q^{r+2})}{1-q}\end{multline}$$

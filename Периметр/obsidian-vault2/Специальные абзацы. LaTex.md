### Сноски
Чтобы сделать сноску используем команду \\footnote, которая может принимать аргумент номера сноски.
Если она не работает, то используем \\footnotemark в проблемном участке, а после него \\footnotetext.

### Перечни
- Простейшие перечни. Создаются с помощью окружения itemize. Представляют из себя символ(жирная точка) и текст. Элемент создаются с помощью команды \\item. \\item принимает необязательный аргумент символа, который ставится вместо жирной точки.
- Нумерованные перечни. Эти перечни создаются с помощью окружения enumerate. Пункт создается с помощью \\item, который не принимает дополнительных аргументов. На пункт можно сослаться с помощью \\label и \\ref. 
- Окружение description создает перечень с заголовками.  \\item принимает необязательный аргумент заголовка. 
-  Чтобы модифицировать символы перечня мы используем \\renewcommand, обращаясь к \\labelitem(римская_цифра_вложенности). Иногда стоит использовать с этим \\mathsurrond для уничтожения дополнительных пробелов. Для enumerate обращаемся к счетчикам enumi


### Разрыв страниц и т.п.
- Чтобы запретить разрыв страниц или уменьшить её приоритетность используем \\nopagebreak, который может принимать значение от 0 до 4
- Для разрыва:
  
| Параметр | Значение | Пример |   
| -------- | -------- | ------------ | 
| \\newpage | страница завершается без какого-либо форматирования | \\newpage
| \\clearpage | аналогично \\newpage, но не трогает иллюстрации| \\clearpage
| \\cleardoublepage | Новая нечетная страница(если четные и нечетные имеют разные оформления)| \\cleardoublepage
| \\pagebreak | Разрывает, но с форматированием. Кроме того, позволяет ставить приоритет| \\pagebreak\[2]
- \\clubpenalty и \\widowpenalty отвечают за висячие строки.
- \\fill — это промежуток нулевой промежуток, но он может бесконечно растягиваться. 


### Линейка
В latex линейки это такие чёрные прямоугольники, которые могут быть использованы для различных целей.
Создается командой \\rule, которая принимает высоту и ширину, а также необязательный аргумент сдвига по вертикали.
Но есть альтернативы:
- \\vrule. Это команда, которая создает вертикальную линейку внутри абзаца, простирающуюся по максимальной и минимальной высоте буквы.
- \\hrule. Команда похожу на \\vrule, но линейка горизонтальная.
- Чтобы настраивать размер этих линеек используем \\width и \\height
Можно задавать нулевые параметры линейки, чтобы она была невидимой, но влияла на документ. \\strut создает линейку с нулевой шириной, но она поднимается на максимальный размер шрифта, а опускается на минимальный размер.

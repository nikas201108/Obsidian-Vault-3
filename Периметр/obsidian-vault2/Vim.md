В vim есть два способа ввода текста:
- Insert(Режим ввода текста)
- Командный 

Чтобы переключаться между ними нажимаем insert

:w — записать документ
:q — выход
:q! — выход без сохранения 
:wq —выход с сохранением

h   — влево 
j  — вниз
k — вверх
l — вправо

Горячие клавиши при входе в режим редактирования текста:
- a — передвигает вправо
- A — переводит в конец строки
- o — ниже текущей строки
- O — выше текущей
- cw — меняет слово

Горячие клавиши:
- gg — переход в начало файла
- G — переход в конец файла
- w — следующее слово
- b — предыдущее слово
- f — поиск по символу в строке 
- / — поиск вниз по символу во всем документе(чтобы найти следующее слово нажимаем n)
-  ? — поиск вверх по символу во всем документе(чтобы найти следующее слово нажимаем n)
- m — создает закладку('имя закладки, чтобы обратиться)
- dw — удаляет слово
- dd — удаляет строку
- u — отменяет действие
- D — удаляет строку справо от курсора

Чтобы перейти в визуальный режим используем букву v.
Горячие клавиши в визуальном режиме:
- x — вырезаем. Чтобы вставить p — справа от курсора и P — слева

Если поставить число перед командой, то команда выполнится n раз

Чтобы начать запись макроса нажимаем q и число. Чтобы применить макрос нажимаем @ и число

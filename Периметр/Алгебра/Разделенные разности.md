Разделенные разности или метод Ньютона — это способ построения <mark style="background: #BBFABBA6;">интерполяционного многочлена</mark>, рекурсивным путем находя <mark style="background: #BBFABBA6;">коэффициент</mark> $a$, по формуле: $$a_0+a_1(x-x_0)+a_2(x-x_0)(x-x_1)+a_3(x-x_0)(x-x_1)(x-x_2)+\ldots$$
$a_k$ — <mark style="background: #BBFABBA6;">разделенная разность</mark>, вычисляемая, как: $$\begin{align}a(x_i)=y_i\\\\a(x_i, \ x_j) = \frac{y_j-y_i}{x_j-x_i}\\\\a(x_i, \ x_j, \ x_k) = \frac{a(x_j, \ x_k) - a(x_i, \ x_k)}{x_k-x_i}\\\\a(x_i, \ \ldots,\ x_a, \ \ldots, \ \ x_n) = \frac{a(x_a, \ \ldots, \ x_n)-a(x_i, \ \ldots, \ x_a)}{x_n-x_i}\end{align}$$

| $a_0$    | $a_1$           | $a_2$                  | $a_3$                         | $a_n$                     |
| -------- | --------------- | ---------------------- | ----------------------------- | ------------------------- |
| $a(x_0)$ | $a(x_0, \ x_1)$ | $a(x_0, \ x_1, \ x_2)$ | $a(x_0, \ x_1, \ x_2, \ x_3)$ | $a(x_0, \ \ldots, \ x_n$) |

>[!tip]
>Вычисление коэффициентов удобно оформлять в виде таблицы

<mark style="background: #BBFABBA6;">Применение</mark>: построение многочлена по заданным точкам

<mark style="background: #BBFABBA6;">Преимущества</mark>: можно добавлять новые точки, не изменяя многочлен

<mark style="background: #BBFABBA6;">Недостатки</mark>: сложна вычислительно и в понимании в отличии от [[Интерполяционный многочлен Лагранжа.pdf|формулы Лагранжа]]

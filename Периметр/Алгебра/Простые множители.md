>[!theorem]+ Формула нахождения количества делителей числа
>Допустим, дано число $b = \alpha_1^{p_1}\alpha_2^{p_2}\ldots\alpha_n^{p_n}$, где $\alpha_1\alpha_2\ldots\alpha_n$ — простые множители. Тогда количество делителей числа ищется по формуле перестановок с учетом добавления варианта, когда степень равна $0$ (простой множитель отсутствует): $$(p_1+1)(p_2+1)\ldots(p_n+1)$$
>>[!example]- Пример
>>Пусть $b=30=2\cdot3\cdot5$. Тогда по формуле количество делителей равно $8$. 
>>Проверим:
>> 
| 2   | 3   | 5   |     |
| --- | --- | --- | --- |
| 0   | 0   | 0   | 1   |
| 0   | 0   | 1   | 5   |
| 0   | 1   | 0   | 3   |
| 0   | 1   | 1   | 15  |
| 1   | 0   | 0   | 2   |
| 1   | 0   | 1   | 10  |
| 1   | 1   | 0   | 6   |
| 1   | 1   | 1   | 30  |
>
>>[!point]- Количество делителей числа
>>Из этой формулы нетрудно сделать вывод, что число всегда имеет чётное число делителей

>[!theorem]+ Неравенство корень из числа и его делители
>Пусть $b = \alpha \cdot \beta$
> Тогда, если $\alpha < \beta$, можно утверждать: $\alpha < \sqrt{b}$
>> [!proof]- Доказательство
>> Допустим, что оба делителя $>\sqrt{b}$. Тогда мы получаем противоречие: $$\begin{align} &b = \alpha \cdot \beta \\\\ &\alpha\cdot\beta>\sqrt{b}\cdot\sqrt{b}>b\end{align}$$
>
>>[!tip]- Применение
>>Данный факт применяется для оптимизации алгоритма поиска простых делителей числа

# НОД
>[!term]+ Определение
>Наибольший общий делитель двух или более натуральных чисел — это наибольшее натуральное число, на которое все эти числа делятся без остатка
>Обозначается как НОД($a, \ b$) или $\mathup{gcd}(a, \ b)$


>[!example|float-right-medium] Пример
>>![[НОК И НОД — медиа 1.png]]

НОД может быть легко определен через разложение чисел на простые множители. 
НОД — простые множители, совпадающие в обоих числах
# НОК

>[!term]+ Определение
>Наименьшее общее кратное двух или более натуральных чисел — это наименьшее натуральное число, которое делится на каждое из этих чисел без остатка
>Обозначается как НОК($a, \ b$) или $\mathup{lcm}(a, \ b)$

>[!example|float-left-medium] Пример
>>![[НОК И НОД — медиа 2.png]]

НОК может быть определен так же через разложение на простые множители, как и НОД. 
Однако в данном случае одно из чисел должно быть умножено на несовпадающие простые члены другого 

# Формальное математическое определение 
Рассмотри числа $a$ и $b$, что $a = k\cdot a_1$, а $b = k\cdot b_1$, где $k$ есть наибольший общий множитель чисел. Тогда: $$\begin{align}&\textup{НОД}(a, \ b) = k\\\\&\textup{НОК}(a, \ b)=k\cdot a_1\cdot b_1\end{align}$$
	
# Связь между НОД и НОК
>[!theorem]+ Связь между НОД И НОК
>Верно утверждать, что для чисел $a$ и $b$ истинно: $$\textup{НОД}(a, \ b) \cdot \textup{НОК}(a, \ b) = a\cdot b$$
>Следовательно, зная один из этих элементов можно вычислить другой 
>>[!proof]- Доказательство
>>Это следует напрямую из формальной записи НОД и НОК: $$\textup{НОД}(a, \ b) \cdot \textup{НОК}(a, \ b) = a\cdot b \Longleftrightarrow k^2 \cdot a_1 \cdot b_1 = k^2\cdot a_1 \cdot b_1$$

>>[!point]- Упрощение с помощью взаимно простых
>>Рассмотрим $\textup{НОД}(ab, \ c)$. Если $a$ и $с$ взаимно простые, то можно утверждать, что: $$\textup{НОД}(ab, \ c) =\textup{НОД}(b, \ c)$$
>>>[!proof]- Доказательство
>>>Запишем формально это равенство: $$\begin{align}&a=a_1 \\ &b=b_1\cdot k\\ &c=c_1\cdot k\\\\&\textup{НОД(ab,\ c)}=\textup{НОД}(a_1\cdot b_1 \cdot k, \ c_1\cdot k) = k = \textup{НОД}(b_1 \cdot k, \ c_1\cdot k)=\textup{НОД(b,\ c)}\end{align}$$
>>>Доказано!
>
>
>
>>[!point]- Вынесение общего множителя и степени
>>Для любых $a, \ b$ верно: $$\begin{align}\textup{НОД}(ka, \ kb) = k\cdot\textup{НОД(a,\ b)}&&\textup{НОД}(a^n, \ b^n) = (\textup{НОД(a,\ b)})^n\end{align}$$
>>>[!proof]- Доказательство
>>>Запишем формально эти два равенства, если $a =a_1\cdot \omega$, $b=b_1\cdot \omega$ $$\begin{align}&\textup{НОД}(k\cdot a_1\cdot\omega ,\ k\cdot b_1\cdot\omega)=k\cdot\omega=k\cdot \textup{НОД(a,\ b)}\\\\\\&\textup{НОД}(a_1^n\cdot\omega^n, \ b_1^n\cdot\omega^n)=\omega^n=\textup{НОД}(a, \ b)^n\end{align}$$
>>>Доказано!
>
>>[!point]- Линейное представление 
>>$$\textup{НОД}(a, \ b) = ax+ by$$
>
>>[!point]- Евклидовы равенства
>>Назовем евклидовыми равенствами, так как они лежат в основе алгоритма Евклида тождества $$\begin{align}&\textup{НОД}(a, \ b) = \textup{НОД}(a-b, \ b)\\\\&\textup{НОД}(a, \ b) = \textup{НОД}(a\mod b, \ b)\end{align}$$
>>>[!proof]- Доказательство
>>>Доказательство данных фактов можно произвести через формальную запись тождеств: $$\begin{align}&a=a_1\cdot k \\&b = b_1\cdot k\\&a>b \\\\&a-b=k\cdot(a_1-b_1)=k\cdot a' \Longrightarrow \textup{НОД}(a, \ b) = \textup{НОД}(a-b, \ b)\\\\&a = b\cdot n 
  +r=b_1\cdot k\cdot n + r = a_1\cdot k \Longrightarrow r = k\cdot(b_1\cdot n - a_1)=k\cdot a' \Longrightarrow \textup{НОД}(a, \ b) = \textup{НОД}(a\mod b, \ b) \end{align}$$
  >
  >>[!point]- Использование кратности чисел
>>В силу доказанного ранее свойства вынесения множителя за НОД для кратных двум чисел корректно: $$\textup{НОД}(a, \ b) = 2\cdot\textup{НОД}(a\div 2, \ b \div 2)$$
>>Для комбинации чётных и нечётных же чисел истинно равенство, так как 2 не может войти в НОД: $$\textup{НОД}(a, \ b) = \textup{НОД}(a\div 2, \ b)$$


Очевидно, что: $$\begin{align}\textup{НОД}(a, \ b) \leq \min (a,\ b)\\\\\textup{НОК}(a, \ b) \geq \max (a,\ b)\\\\\end{align}$$

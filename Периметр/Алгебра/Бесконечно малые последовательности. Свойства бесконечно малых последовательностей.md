>[!term]- Бесконечно малая последовательность
>Бесконечно малая последовательность — это последовательность, где каждый $n$-ый элемент начиная с $N$ будет меньше заранее взятого числа $\epsilon$: $$|x_n| < \epsilon$$
>>[!example]- Пример
>>![[Бесконечно малые последовательности. Свойства бесконечно малых последовательностей — медиа 5.png]]

>[!rule]- Сумма двух бесконечно малых последовательностей есть бесконечная малая последовательность
>![[Бесконечно малые последовательности. Свойства бесконечно малых последовательностей — медиа 4.png]]

>[!rule]- Произведение ограниченной последовательности на бесконечно малую есть бесконечно малая последовательность
>![[Бесконечно малые последовательности. Свойства бесконечно малых последовательностей — медиа 3.png]]

>[!rule]- Бесконечно малая последовательность, где $x_n=c$, может состоять только из нулей
>![[Бесконечно малые последовательности. Свойства бесконечно малых последовательностей — медиа 2.png]]

>[!rule]- Связь бесконечно малой и бесконечно большой последовательностей

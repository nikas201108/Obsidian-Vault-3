State machines (Конечный автомат) — это структура, метод моделирования, где результат зависит не от единичного входного значения, а от множество таких значений и порядка их поступления

Для описания State machines достаточно:
- Определить `S` — состояния
- Определить `I` — входы или input vocabulary
- Определить `O` — выходы или output vocabulary
- Определить функцию, отвечающую за зависимость следующего состояния от текущего входа
- Определить выходную функцию
- Определить изначальное состояние

>[!warning]
>Выходная функция не должна менять состояние машины. Она может его только возвращать
>


| SM (суперкласс)                                                                                         | SM_sub (подкласс)                                                                       |
| ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| state — меняющееся состояние                                                                            | `startState` — начальное состояние, которые присваивается `state` и больше не меняется  |
| `def start()` — функция, которая запускает машину, присваивает `state` `StartState`                     | `def getNextValues (state, inp)` — функция, возвращающая значение и следующее состояние |
| `def step(inp) -> out` — функция, которая на каждом шаге вызывает функции вывода и обновления состояния |                                                                                         |
| `def transduce(inp) -> out` — функция, реализующая чтение потока                                        |                                                                                         |
| Опционально: стандартная реализация `def getNextState`                                                  |                                                                                         |


Могут быть:
- Непреревными (дифференциальные уравнения)
- Дискретными

Конечные автоматы, к примеру, позволяют реализовать:
- Пользовательские интерфейсы
- Считывание последовательностей ДНК
- Панель состояний того или иного прибора
- Счётчики
- Delay (когда сохраняем вход и даём его на следующем шаге)
- Accumulator
- Selector (взятие каждого k-ого элемента из массива)

Варианты компоновки:
- Последовательная (`Cascade`)
- Параллельная (`Parallel`)

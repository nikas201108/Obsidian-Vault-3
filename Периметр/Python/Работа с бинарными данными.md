# Представление
Бинарный формат в Python представлен типами `bytes`, что представляет собой кортеж, и `bytearray`:
```python
bytes([11, 10, 245, 88, 255]) # b'\x0b\n\xf5X\xff'
bytearray([11, 10, 245, 88, 255]) # b'\x0b\n\xf5X\xff'
```
Python старается выводится значение либо в виде символа, либо в шестнадцитиричном формате

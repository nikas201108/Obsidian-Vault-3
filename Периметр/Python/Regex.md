re — это встроенная библиотека Python, которая позволяет использовать [[Регулярные выражения|регулярные выражения]]

```python
import re
```


<mark style="background: #BBFABBA6;">Шаблоны</mark> записываются в виде обычной строки. Часто требуется добавлять перед строкой литерал строковый литерал `r`, чтобы избежать проблем с использованием косой черты.
```python
regex = r'\d'
```

Поиск может вестись как по отдельным <mark style="background: #BBFABBA6;">символам</mark>, так и по <mark style="background: #BBFABBA6;">диапазонам</mark> или <mark style="background: #BBFABBA6;">критериям</mark>, заданными встроенными спецсимволами
```python
regex = r'hello' #шаблоном будет слово „hello“
regex = r'\d' #шаблоном будут все числа
regex = r'.\d' #шаблоном будет любой символ и следующий за ним цифра
regex = r'[G-zП-я]' #шаблоном будет промежуток чисел от большой G до z и от П до я
regex = r'[АУЮЕОЯ]{2}' #шаблоном будут все заглавные гласные, повторяющиеся два раза
```

<mark style="background: #BBFABBA6;">Спецсимволы</mark>:
- `.` — любой символ, кроме новой строки
- `\d` — любая цифра
- `\D` — любой символ, кроме цифры
- `\s` — любой пробельный символ
- `\S` — любой непробельный символ
- `\w` — любая буква, цифра и __
- `\W` — любая не-буква, не-цифра и неподчеркивание
- `\b` — начало или конец слова
- `\B` — не начало или не конец слова
- `[]` — один из символов в скобках
- `[!]` — все, кроме символов в скобках

<mark style="background: #BBFABBA6;">Квантификаторы</mark>:
- `\{n}` — n повторений
- `\{m,n}` — от m до n повторений включительно
- `\{m,}` — не менее m повторений
- `{,n}` — не более n повторений
- `?` — ноль или одно включение 
- `*` — ноль или более включений
- `+` — одно или более включений

<mark style="background: #BBFABBA6;">Основные функции</mark>:
- `re.search()`  — найти первое вхождение
- `re.fullmatch()` — проверить полностью ли совпадает строка
- `re.split()` — аналогично `str.split()`
- `re.findall()` — найти все пересекающиеся подстроки
- `re.sub()` — заменить пересекающиеся подстроки на другую подстроку
- `group.match()` — обратиться к группе


<mark style="background: #BBFABBA6;">Шаблонные конструкции</mark>:
- `(?:)` — объединение
- `(?:)|(?:)` — или
- `(?=)` — позитивный просмотр вперёд
- `(?!)` — негативный просмотр вперёд
- `(?<=)` — позитивный просмотр назад
- `(?<!)` — негативный просмотр назад
- `(?P<name>)` — именованная группа

Флаги для функций:
- `re.ASCII` — ограничение только на ASCII
- `re.IGNORECASE` — игнорирование регистра
- `re.DOTALL` — включение в `.` переход на новую строку
- `re.MULTILINE` — взаимодействие с текстами

#Геометрия 

### Утверждение
Центр описанной окружности вокруг прямоугольного треугольника есть середина его гипотенузы

![[Центр описанной окружности вокруг прямоугольного треугольника есть середина его гипотенузы — медиа 1.png]]

### Доказательство 
Можно:
1. Через теорему синусов, где $c = 2R$
2. Можно через медиану из прямого угла в прямоугольном треугольнике, которая будет равна половине гипотенузы. Там через прямое определение описанной окружности

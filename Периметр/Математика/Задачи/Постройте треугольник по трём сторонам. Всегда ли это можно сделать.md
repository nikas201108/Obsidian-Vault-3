#Геометрия

Задача А15

## Условие
Постройте треугольник по трём сторонам. Всегда ли это можно сделать?

## Решение
Любой треугольник можно построить по трём сторонам, если:
- $a + b < c$
- $a + c < b$
- $c + b < a$

Для этого необходимо просто взять и с помощью линейки построить стороны необходимой длинны или потанцевать с циркулем

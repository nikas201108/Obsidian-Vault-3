## Определение
Логарифм — это степень, в которую надо возвести число $a$, чтобы оно стало числом $b$
$$a^c=b\Leftrightarrow \log_ab = c$$
Здесь:
- $a$ — основание логарифма. $a > 0$ и $a\neq 1$ 
- $b$ — подлогарифмичное выражение
- Читается  «логарифм по основанию $a$ от $b$»

Примеры:
- $\log_2 8 = 3$
- $\log_6 36 = 2$
- $\log_\frac{1}4 \frac{1}{16} = 2$ 

Существуют некоторые особо закрепленные логарифмы:
- Логарифм по основанию десять — десятичный логарифм, обозначаемый $\lg a$ 
- Логарифм по основанию $e$ — натуральный логарифм. Обозначается $\ln a$

Если $b>0$ и $a>0$ и $a \neq 1$, то найдется единственное решение, что $a^c = b$, значит значение логарифма существует и единственно 

## Свойства
### Основное логарифмическое тождество
Основное логарифмическое тождество выглядит так:$$a^{\log_a b} =b$$
Само по себе оно следует из определения логарифма: мы возводим число $a$ в степень, в которую его необходимо возвести для получения числа $b$

### Другие тождества из определения
Нетрудно заметить, что:
- $\log_aa = 1$
- $\log_a1 = 0$

Кроме того, из определения также следует: $$\log_aa^x=x$$
### Сложение и вычитание логарифмов
- $\log_a b + \log_a c = \log_a bc$
  Чтобы доказать это, скажем: $\log_a b = x \to b = a^x$ и $\log_a c = y \to c = a^y$. Тогда: $$\log_abc= \log_aa^xa^y=\log_aa^{x+y}=x+y=\log_ab+\log_ac$$
- $\log_a b - \log_a c = \log_a \dfrac{b}{c}$
  Чтобы доказать это, опять скажем: $\log_a b = x \to b = a^x$ и $\log_a c = y \to c = a^y$. Тогда: $$\log_a\frac{b}{c}=\log_a\frac{a^x}{a^y}=\log_aa^{x-y}=x-y=\log_ab-\log_ac$$
### Степени подлогарифмического выражения и основания
- $\log_ab^m=m\log_ab$
  Чтобы это доказать, скажем: $\log_a b = x\to b = a^x$. Теперь смотрим: $$\log_ab^m=\log_aa^{x\cdot m} = x\cdot m = m\log_ab$$
- $\log_{a^n}b=\dfrac1n\log_ab$
  Чтобы доказать это, опять скажем: $\log_a b = x\to b = a^x$. Теперь смотрим: $$\log_{a^n}b=\log_{a^n} a^x=\left(\frac{nx}{n}\right)=\log_{a^n} a^{\frac{nx}{n}}=\log_{a^n} (a^n)^{\frac{x}{n}}=\frac{x}n=\frac{1}{n}\log_ab$$
### Переход к новому основанию
$$\log_a b =\dfrac{\log_cb}{\log_ca}$$
Пусть $\log_a b = x \to b = a^x$. Тогда: 

$$\dfrac{\log_ca^x}{\log_ca}=\dfrac{x\log_ca}{\log_ca}=x=\log_ab$$

И его частный случай, позволяющий избавиться от числителя: $$\log_ab = \dfrac{1}{\log_ba}$$

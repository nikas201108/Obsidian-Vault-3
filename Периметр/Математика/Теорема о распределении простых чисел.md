при всяком целом $n$ обозначим через $A_n$ число простых чисел среди чисел $1,\ 2,\ 3,\ \ldots,\ n$. 

Возьмем постоянно возрастающую последовательность чисел $n = 10, \ 10^2, \ 10^3, \ \ldots$ 
Тогда числа $A_{10}, \ A_{10^2}, \ \ldots$ тоже будут расти бесконечно.

Посчитаем отношения $\dfrac{A_n}{n}$. 

|$n$| $\dfrac{A_n}{n}$ |
| -------- | -------- |  
| $10^3$ | $0,168$ |
| $10^6$ | $0,078498$ |
| $10^9$ | $0,050847478$ |

Тут надо вспомнить определение натурального логарифма числа $n$.
Было замечено, что $\dfrac{A_n}{n}:\dfrac{1}{\ln n}$ примерно как $1:1$ и точность этого приближения улучшается при возрастании $n$

|$n$| $\dfrac{A_n}{n}:\dfrac{1}{\ln n}$ |
| -------- | -------- |  
| $10^3$ | $1,159$ |
| $10^6$ | $1,084$ |
| $10^9$ | $1,053$ |

Значит $\dfrac{A_n}{n}$  асимптотически равно $\dfrac{1}{\ln n}$ или по-другому $$\lim_{n\rightarrow \infty} \frac{A_n}{n}:\frac{1}{\ln n } = 1$$ $$\frac{An}{n}\sim\frac{1}{\ln n}$$

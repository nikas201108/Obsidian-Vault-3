Формулы для решения:
	a) Теорема косинусов: $a^2 = b^2+c^2-2\times b\times c\times \cos \alpha$
	б) Следствие теоремы синусов: $\dfrac{a}{\sin \alpha} = 2R$

Сделаем рисунок задачи:
![[Pasted image 20240423155253.png]]

1) Проведём $DE$ при условии, что $AC \parallel DE$, и соединим вершину $E$ с вершиной $A$:![[Pasted image 20240423155635.png]]
2) Найдем $\angle BAE$:
   1. $\angle CKD = \angle KDE$ ($AC \parallel DE$ сек. $KD$)
   2. Четырёхугольник $ABDE$ вписан в окружность, значит $\angle BAE = 180 - \alpha$
3) Так как описанная трапеция может быть только равнобедренной, то $AE = CD$ 
4) Проведём диагональ $BE$:![[Pasted image 20240423170515.png]]
   По теореме косинусов в треугольнике $BAE$: $$BE^2 = AB^2+ AE^2 -2\times AB \times AE \times \cos \angle BAE$$
   5) По теореме синусов: $$\dfrac{BE}{\sin \angle BAE} = 2R;\text{  }R = \dfrac{BE}{2\sin\angle BAE}$$

>$\alpha = 60$

Начнём  с пункта 4.

5) $R = \sqrt{133}$

Важные формулы перед решением:
a) Медиана проведенная из прямого угла равна половине гипотенузы

Сделаем рисунок:
![[Pasted image 20240422173941.png]]

1) Достроим трапецию до треугольника, продлив боковые стороны и продолжив $LN$. Можно заметить, что сумма углов у оснований трапеции будет $90^\circ$, а значит треугольник будет прямоугольный ![[Pasted image 20240422174258.png]]
2) Так как по условию $AN = ND$, то отрезок $EN$ — медиана. $EN = AD\times 0.5$. По такому же принципу $EL = BC\times 0.5$
3) Выводим формулу вертикальной средней линии через основания:$$LN = EN-EL=\dfrac{AD-BC}{2}$$
4) По определению средней линии в трапеции:$$MK = \dfrac{AD+BC}{2}$$
5) Решаем систему уравнений:$$\left\{ \begin{aligned} &MK = \dfrac{AD+BC}{2}\\&LN =\dfrac{AD-BC}2{}\end{aligned}\right.$$
	
## Пример

>[!info] Входные данные
>$M_1 = 43$
>$M_2 = 47$
>$a = 16$
>$b = 14$


Начнём с пункта 1.
1) $180-M_1-M_2 = 180- 43-47 = 90$. Действительно прямоугольный треугольник
5) :$$\left\{ \begin{aligned} &16 = \dfrac{AD+BC}{2}\\&14 =\dfrac{AD-BC}2{}\end{aligned}\right.$$
   $$AD = 30;\text{  } BC = 2$$

1) Проведем из точки $L$ перпендикуляр $LH$:
   ![[Pasted image 20240420212026.png]]
   Можно заметить, что четырёхугольник $BAO_2H$ является прямоугольникам по трём прямым углам(два из которых образованы радиусами к касательным) и это означает $AO_2 = BH$
2) Из пункта 1 следует, что: $$HO_1=BO_1-BH=R_1-R_2$$
3) По определению в прямоугольном треугольник $\triangle O_2HO_1$ $$\cos{\angle O_2O_1H} = \dfrac{HO_1}{O_1O_2} = \dfrac{R_1-R_2}{R_1+R_2}$$
4) $\angle LO_1B = \angle LO_2A$ (соответственные углы при сек. $LO_1$ и $AC \parallel BD$)
5) Рассмотрим $\triangle AO_2L$: $$O_2L = AO_2\times \cos{\angle AO_2L} = R_2\times \cos{\angle AO_2L}$$
6) Рассмотрим $\triangle BMO_1$: $$O_1M = BO_1\times \cos{\angle BO_1M} = R_1\times \cos{\angle BO_1M}$$
7) $$LM = O_2O_1-MO_1+LO_2$$
# Пример

>[!info] Входные данные
>$R_1 = 20$
>$R_2 = 12$ 

Начнём с пункта 3:
3) $$\cos{\angle O_2O_1H}  = \dfrac{20-12}{20+12}=\dfrac{1}4$$
4) $$O_2L=12\times\dfrac14=3$$
6) $$O_1M=20\times\dfrac14=5$$
7) $$LM = 32-5+3=30$$

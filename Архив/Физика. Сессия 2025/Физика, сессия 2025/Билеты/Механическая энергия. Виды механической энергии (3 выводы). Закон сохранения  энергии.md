# Материал
Энергия — это физическая величина, показывающая какую работу может выполнять тело
$A = \Delta E$ (работа равна изменению энергии), единая мера различных форм движения материи и мера перехода движения материи из одних форм в другие 

Консервативная система тел — система с только потенциальными силами (потенциальные — две точки, непотенциальные — траектория)

Механическая энергия — характеристика движения и взаимодействия сил тел, функция скоростей и взаимного расположения

Кинетическая энергия — энергия движущегося тела

Потенциальная энергия — энергия взаимодействия тел (положение во внешнем силовом поле), частей тела

Изменение кинетической энергии — все работы
Изменение потенциальной энергии — потенциальные работы

#### Закон сохранения энергии
$$E_п+E_к=const$$
В замкнутых системах полная механическая энергия остается величиной постоянной

Доказать это можно так: $$\left\{\begin{align}&A = \Delta E_{кин} = E_{кин2}-E_{кин1}\\\\&A = -\Delta E_{пот} = E_{пот1}-E_{пот2}\end{align}\ \ \ \ \ \Longrightarrow E_{кин1} +E_{пот1}=E_{кин2}+E_{пот2}\right.$$

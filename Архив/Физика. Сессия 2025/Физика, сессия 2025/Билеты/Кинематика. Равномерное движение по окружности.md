# Материал



Равномерное движение по окружности — это движение по окружности при постоянной скорости

![[Pasted image 20250420123658.png]]

Линейная скорость (скорость движения по окружности) во время равномерного движения по окружности не изменяется 

При таком движении отсутствует тангенциальное ускорение, но есть нормальное (центростремительное) ускорение 

При рассмотрении такого движения удобно использовать полярную систему координат, где положения задается полярным углом и длинной радиус-вектора
![[Pasted image 20250420124141.png]]

Отсюда можно ввести понятие средней угловой скорости и мгновенной угловой скорости (как меняется угол поворота с течением времени): $$\begin{align}\omega_{ср} = \frac{\Delta \phi}{\Delta t}&&\omega=\lim_{\Delta t\to 0} \omega_{ср}\end{align}$$
В случае равномерного движения они совпадают

Частота — это количество оборотов за единицу времени
Период — это время, за которое тело совершает один оборот
$$\begin{align}T =\frac{t}{N} =\nu^{-1} &&\nu = \frac{N}{t}=T^{-1}\end{align}$$
Отсюда: $$\omega = \frac{2\pi}{T}$$
Скорость можно выразить по-разному: $$v=\frac{2\pi R}{T}=\omega R$$
(Ускорение выводится отдельно)
Отсюда ускорение: $$a = \frac{v^2}{R}=\frac{4\pi^2R}{T^2}=\omega^2R$$
Любая формула с периодом может быть заменена формулой с частотой
